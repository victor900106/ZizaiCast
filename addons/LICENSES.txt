Mirror of third-party release files for 自在投影 / Zizai Cast (0.7.7 and later)
=============================================================================

Upload these files unchanged to the gh-pages branch at
  addons/llama-b11514-bin-win-cpu-x64.zip
  addons/llama-b11514-bin-win-vulkan-x64.zip
so they are served at https://victor900106.github.io/ZizaiCast/addons/<file name>.
The app tries that URL first and falls back to the original GitHub release
(https://github.com/ggml-org/llama.cpp/releases/tag/b11514) when it is
missing; either way the SHA-256 below is checked before a file is used.

  e1eaddcde761b1f839b9c6d5924b97f2698fba22068ca3b63f129c3caf55b88f  llama-b11514-bin-win-vulkan-x64.zip  (33,446,009 bytes)

These are the official, unmodified builds of llama.cpp release b11514
(commit de7fa0a3c6a2e1b4cd9f22eb8d6bf5b12dbdb63b) by the ggml authors, as
listed on the release page.  Source: https://github.com/ggml-org/llama.cpp/tree/b11514
