自在投影（ZizaiCast）— 第三方元件授權說明
==========================================

自在投影是自由軟體，依 GNU 通用公共授權條款第 3 版（GPL-3.0）散布，
授權全文見程式資料夾中的 LICENSE.txt。每個版本的完整對應原始碼
（Corresponding Source）都附在與安裝程式相同的 GitHub Release 頁面：
    https://github.com/victor900106/ZizaiCast/releases
    ZizaiCast-<版本>-source.zip       （本程式原始碼＋建置說明）
    ZizaiCast-<版本>-deps-source.zip  （下列函式庫的原始碼）
詳見原始碼壓縮檔中的 docs/licenses/SOURCE.md。

本文件列出安裝程式所含的每一個第三方元件：版本、來源、授權、著作權聲明，
並於附錄收錄授權條款全文。各元件的授權條款以原文（英文）收錄，以原文為準。
英文版：THIRD_PARTY_NOTICES.txt。

美術圖像：吉祥物「投投」（Toutou）與程式圖示是本專案的原創作品（原始檔在
assets/public/toutou/，程式內嵌的圖層在 video/res/toutou/，圖示為 app/res/app.ico），
屬於本程式的一部分，與程式碼同樣依 GPL-3.0 散布，並包含在原始碼壓縮檔中。
0.6.0 以前版本使用過的舊吉祥物／圖示圖像已全部移除，不再散布。

本文件與英文版、SOURCE.md 一同安裝在程式資料夾的 程式\licenses\
（關於自在投影 →「開啟授權資訊資料夾」，或安裝資料夾裡的「授權資訊」捷徑）。

  Apple 的法律地位不明確。
* FFmpeg 必須維持 LGPL 組態（不得啟用 gpl／version3／nonfree 功能）。
