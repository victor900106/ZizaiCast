自在投影 · 使用教學

把手機畫面，
放到電腦上。

iPhone、iPad 與 Android 手機都可以投影到這台 Windows 電腦。先看第 1 節確認網路，再依照你的手機跳到對應的章節。

iPhone · iPad螢幕鏡像控制中心點一下就好，有畫面也有聲音。 Android 方式一投放（Miracast）不用設定，但電腦要支援無線顯示器。 Android 方式二無線偵錯第一次要設定，之後可以用滑鼠操控手機。

1開始之前

手機是透過網路找到電腦的。大部分「找不到自在投影」的狀況，都出在這一節。

  1. 同一個 Wi-Fi／區域網路。手機連的 Wi-Fi，和電腦連的必須是同一台分享器。電腦用網路線接在同一台分享器上也可以。手機上的「行動數據」或「個人熱點」不算。
  2. 第一次執行時允許防火牆。開啟自在投影時，如果 Windows 跳出「Windows 安全性警示」，請勾選私人網路並按允許存取。按了取消的話，手機會找不到這台電腦（解法見常見問題）。
  3. 先把 VPN 關掉。電腦或手機開著 VPN 時，連線常常被導到別的網路，手機就看不到電腦。投影時請先中斷 VPN。
  4. 學校、公司、飯店的網路可能不行。這類網路常開啟「用戶端隔離」或封鎖裝置探索，手機和電腦即使連同一個 Wi-Fi 也互相看不到。「訪客網路」通常也是如此。這時可以改用家裡的網路，或用電腦開熱點讓手機連上。
自在投影平常在哪裡？ 關掉視窗並不會結束程式，它會縮到右下角的系統匣（時鐘旁邊的小圖示）繼續等待連線。手機一連上，視窗會自動跳出來。

2iPhone / iPad

使用 Apple 內建的「螢幕鏡像」，不用安裝任何 App。畫面和聲音都會一起傳到電腦。

開始投影

  1. 確認電腦上的自在投影已經開著（視窗顯示「等待 iPhone 連線…」，或右下角系統匣有它的圖示）。
  2. 打開 iPhone 的控制中心：有 Face ID 的機型從右上角往下滑；有主畫面按鈕的機型從底部往上滑。
  3. 點螢幕鏡像（舊版 iOS 叫「螢幕鏡像輸出」）。
  4. 在清單中選自在投影。幾秒內電腦就會出現手機畫面，並顯示「已連線」。

停止投影

再打開控制中心 → 螢幕鏡像 → 停止鏡像輸出。電腦會回到等待畫面。

也可以在電腦上中斷：滑鼠移到投影畫面上 → 上方工具列最右邊的紅色中斷連線，或按 CtrlD（詳見第 5 節「怎麼中斷連線」）。

如果是 Wi-Fi 斷掉之類的意外中斷，畫面會先變暗並顯示「連線中斷，在 iPhone 重新選擇螢幕鏡像即可」，照著重新選一次就好。

PIN 碼模式

在等待畫面勾選連線時需要輸入 PIN 碼（或在右鍵選單 → 設定、系統匣選單裡切換）。開啟後，新的 iPhone 選自在投影時，電腦會顯示 4 位數字，在 iPhone 上輸入才能投影。

  • 每次嘗試的 PIN 都不一樣；輸錯了 iPhone 會再問一次。
  • 輸入成功過的 iPhone 會被記住，下次不用再輸入。
  • 適合放在共用空間、怕被別人誤連的電腦。投影中切換這個選項，會等手機中斷後才生效。

多支 iPhone

同一時間只會顯示一支手機。另一支 iPhone 也選了自在投影時怎麼辦，可以在右鍵選單 → 設定 → 新手機連線時選擇：

選項效果
接手（預設）換新的那支投影，原本那支自動停止。畫面上會顯示「「某某」接手投影」。若正在錄影，原本那支的錄影會先儲存。
保持目前正在投影的那支繼續，其他手機的連線會被拒絕。適合上課、簡報時避免被打斷。

開啟 PIN 碼模式時，新手機也必須先輸入 PIN（或是曾經配對過）才能接手。

螢幕關閉時

iPhone 鎖定或螢幕關閉時，投影會暫停，電腦顯示「iPhone 螢幕已關閉」。解鎖 iPhone 後會自動繼續，不用重新連線。錄影中暫停也不會中斷錄影。

音量

投影時，iPhone 側邊的音量鍵會直接調整電腦播放的音量，自在投影會記住上次的音量。電腦本身的系統音量也一樣有效。若沒有聲音，請看常見問題。

3Android 方式一：投放（Miracast）

大多數 Android 手機內建「無線投影」功能（Miracast）。不用任何設定，但只能看畫面，不能用電腦操控手機；而且電腦的 Wi-Fi 網卡必須支援。

開始投放

  1. 電腦開著自在投影，並且 Wi-Fi 是開啟的（即使電腦用網路線上網，無線網卡也要開著）。
  2. 手機從螢幕頂端往下滑兩次，打開完整的快速設定。找到投放圖塊（名稱見下表）。找不到的話，點快速設定的「編輯」（鉛筆圖示）把它加進來。
  3. 在搜尋到的裝置清單裡選自在投影（有些手機會顯示電腦名稱）。第一次連線可能要等 10～20 秒。
  4. 停止：再點一次同一個圖塊，或下拉通知欄點「中斷連線」。在電腦上：工具列的中斷連線或 CtrlD。

電腦需要什麼

Miracast 是手機直接以 Wi-Fi 連到電腦（Wi-Fi Direct），所以電腦必須有支援「無線顯示器」的 Wi-Fi 網卡。大部分近年的筆電都支援；桌機若只有網路線、沒有 Wi-Fi 網卡就不能用。檢查方法：

  1. 在「開始」按右鍵 →終端機（或搜尋「命令提示字元」）。
  2. 輸入下面這行並按 Enter：
netsh wlan show drivers

在結果裡找這一行（中文 Windows 可能顯示為「支援無線顯示器」）：

Wireless Display Supported: Yes (Graphics Driver: Yes, Wi-Fi Driver: Yes)

兩個都是 Yes 才能用。如果是 No，可以先更新 Wi-Fi 網卡與顯示卡驅動程式；還是 No 的話，請改用方式二。

小提醒

  • 手機和電腦盡量靠近一點，中間少一點牆壁，畫面會比較穩。
  • Miracast 的連線方式不經過分享器，所以它不受第 1 節的「同一個網路」限制，但電腦的 Wi-Fi 一定要開著。
  • 這種方式無法用電腦操控手機，只能看。想用滑鼠點手機，請用方式二。
  • 連不上時，請看常見問題的Miracast 連不上。

4Android 方式二：無線偵錯

利用 Android 內建的「無線偵錯」功能連線。第一次需要花幾分鐘設定，之後就會自動連線，而且可以用電腦的滑鼠和鍵盤操控手機。需要 Android 11 以上，手機和電腦要在同一個網路（見第 1 節）。

步驟一：開啟「開發人員選項」

這是 Android 隱藏的設定頁，只要做一次。

  1. 打開手機的設定 → 關於手機。
  2. 找到版本號碼，連續點 7 下，直到出現「你現在已成為開發人員」之類的提示。
  3. 回到設定，就會多出開發人員選項（通常在「系統」裡，或設定的最下方）。
品牌要連點的項目開發人員選項在哪
Google Pixel 等關於手機 → 版本號碼設定 → 系統 → 開發人員選項
Samsung關於手機 → 軟體資訊 → 版本號碼設定最下方 → 開發人員選項
Xiaomi / Redmi / POCO我的裝置（關於手機）→ 全部參數 → MIUI 版本（HyperOS 為「OS 版本」）設定 → 更多設定 → 開發者選項
OPPO / realme / OnePlus關於手機 → 版本 → 版本號碼設定 → 系統設定 → 開發人員選項
vivo / iQOO系統管理（關於手機）→ 軟體版本號設定 → 系統管理 → 開發人員選項

步驟二：配對（只要一次）

  1. 手機：開發人員選項 → 打開無線偵錯的開關（第一次會問「要允許在這個網路上使用無線偵錯嗎？」，選允許）。
  2. 電腦：在自在投影視窗按右鍵 → 連接 Android（掃 QR），畫面會出現 QR 圖碼。
  3. 手機：點「無線偵錯」這幾個字進入設定頁 → 使用 QR 圖碼配對裝置，用跳出的相機框掃描電腦上的 QR 圖碼。
  4. 配對成功後，配對視窗會自動關閉，電腦出現手機畫面，下方提示「已連線：手機名稱。滑鼠移到上方有工具列；右鍵＝返回」。
一直停在「等待手機掃描…」？ 約 45 秒都沒有收到手機回應時，視窗會改成顯示「沒有收到手機回應：確認手機和電腦在同一個 Wi‑Fi，或改用配對碼」。請確認兩邊在同一個網路（不是訪客 Wi‑Fi），或按用配對碼：在手機點「使用配對碼配對裝置」，把手機上顯示的 IP 位址:連接埠和 6 位數配對碼輸入電腦。配對失敗時視窗會說明原因，並自動換一個新的 QR 圖碼，直接再掃一次即可。

之後：自動重新連線

配對過的手機不用再掃 QR。只要手機的無線偵錯開著、和電腦在同一個網路，自在投影就會自動連上。

無線偵錯會自己關掉 為了安全，很多手機在重新開機或換了 Wi-Fi 之後，會自動關閉無線偵錯。這時只要回到開發人員選項把它再打開，不用重新配對。

在手機畫面外的黑色區域按兩下，一樣可以切換全螢幕。

右鍵是「返回」，那選單在哪裡？ 在 Android 畫面上按右鍵會送到手機當成返回，所以不會跳出自在投影的選單。要打開選單：把滑鼠移到畫面上方，點工具列的⋯ 更多（或在工具列上按右鍵）；也可以在手機畫面外的黑色區域按右鍵，或按住 Shift 再按右鍵。
Esc 會送到手機（大多數 App 當成返回）；全螢幕時 Esc 則是離開全螢幕。Ctrl 組合鍵是自在投影的快捷鍵，不會送到手機（CtrlC／V／X／A／Z 除外）。

結束投影（中斷連線）

  • 電腦：滑鼠移到畫面上 → 工具列最右邊的紅色中斷連線；或按 CtrlD；或在右下角系統匣圖示按右鍵 →中斷連線（手機名稱）。
  • 從電腦中斷後，這支手機不會自動重新連上，直到下次用「連接 Android（掃 QR）」配對（或重新開啟自在投影）。
  • 手機：把無線偵錯關掉。手機關掉無線偵錯或離開 Wi‑Fi 時，電腦幾秒內就會回到等待畫面，顯示「Android 已中斷」。
安全提醒 開著無線偵錯時，同一個網路上已配對的電腦可以存取這支手機。不需要投影時，請把無線偵錯關掉；在公共 Wi-Fi 上不要開啟。如果想取消某台電腦的權限，可以在無線偵錯設定頁的「已配對的裝置」中移除它。

5功能與快捷鍵

投影中把滑鼠移到畫面上，上方會出現工具列；在投影視窗上按右鍵可以打開所有功能（Android 畫面上右鍵是返回，請用工具列的「更多」）。快捷鍵要在視窗是作用中（點過一下）時才有效。介面語言可以在 設定 → 語言 / Language 切換（自動／繁體中文／English）。

投影中的工具列

  • 滑鼠一移動就出現，停在工具列上不會收起；滑鼠離開視窗或 2 秒沒動就淡出。收起時不會擋到畫面，也不會攔住點擊。
  • 把滑鼠停在按鈕上會顯示名稱和快捷鍵。點工具列不會傳到手機。
  • 錄影在錄影中會變成紅色（再按一次停止）；更多打開完整的右鍵選單。

怎麼中斷連線

iPhone、Android 投放、無線偵錯都一樣，任選一種：

  1. 工具列最右邊的紅色中斷連線。
  2. 按 CtrlD。
  3. 右鍵選單（或工具列的「更多」）最上面的中斷連線。
  4. 右下角系統匣圖示按右鍵 →中斷連線（手機名稱），視窗縮到系統匣時也能用。

正在錄影時會先停止並儲存。iPhone 被中斷後，手機上的螢幕鏡像會停止，要再投影就重新選一次自在投影。

截圖 CtrlS

存到安裝資料夾的「截圖」資料夾，檔名像「自在投影_日期_時間.png」。右鍵選單 → 開啟截圖資料夾。

中斷連線 CtrlD

結束目前的投影，回到等待畫面。也在工具列（紅色按鈕）、右鍵選單與系統匣選單裡。

錄影 CtrlR

再按一次停止。存成含聲音的 MP4，放在「錄影」資料夾。手機中斷、被接手或關閉程式時會自動停止並儲存。磁碟剩不到 300 MB 時無法錄影。

全螢幕 F11

或在畫面上按兩下。按 Esc 離開。

視窗置頂 CtrlT

讓投影視窗永遠在其他視窗上面，一邊工作一邊看手機。

工具列

滑鼠移到畫面上就出現：（Android：返回、主畫面、最近使用）截圖、錄影、旋轉、全螢幕、更多、中斷連線。

旋轉、翻轉

Ctrl→ / Ctrl← 旋轉 90°，CtrlH 左右翻轉，Ctrl0 還原。在右鍵選單 → 畫面。

iPhone 外框 CtrlF

在畫面外加上手機外框；開著外框時，截圖也會帶外框（背景透明）。

主題

櫻花粉、薄荷綠、夜空藍、奶茶。等待畫面和選單會一起換色。

開機自動啟動

登入 Windows 後在背景待命，手機一連線視窗就出現。在等待畫面或系統匣選單勾選。

畫質

右鍵選單 → 設定 → 畫質。數字越高越清楚，但網路和電腦的負擔也越大。

選項解析度說明
標準1080p最省資源，網路不穩或電腦較舊時使用。
高（建議，預設）1440p清楚又順暢的平衡點。
最高4K大螢幕、看細節時使用，需要穩定的 5 GHz Wi-Fi。
「高」「最高」是灰色的？ 這兩種畫質使用 HEVC（H.265）格式，電腦要安裝 Microsoft Store 的「HEVC 影片延伸模組」才能播放。沒有安裝時會自動使用「標準」。安裝後重新開啟自在投影即可選擇。畫質目前主要套用在 iPhone / iPad 的投影。

系統匣

按視窗右上角的關閉，自在投影會縮到右下角系統匣繼續待命（第一次會提示）。點系統匣圖示可以叫出視窗；在圖示上按右鍵可以錄影、切換設定、開啟資料夾，投影中還有中斷連線（手機名稱）。要真正結束：系統匣圖示按右鍵 → 結束。

自動更新

自在投影每天會自動檢查一次新版本，也可以在選單點檢查更新。放進安裝資料夾裡安裝檔資料夾的新版安裝程式，也會自動被發現。

有新版本時，畫面下方會提示「有新版本 vX.Y.Z」，選單最上面、等待畫面和投影時的工具列（↑ 圖示）都會出現更新到 vX.Y.Z。自在投影不會自己更新、也不會打斷投影；按下後才會（需要時下載並驗證）安裝，完成後自動重新開啟並顯示「已更新到 vX.Y.Z」。正在錄影時會先問你，錄影內容會先儲存。

Esc全螢幕時：離開全螢幕；Android 投影時：送到手機（多半是返回）

6常見問題

點問題展開答案。

手機的清單裡找不到「自在投影」
  • 確認自在投影正在執行（系統匣有圖示）。
  • 手機和電腦連的是同一個 Wi-Fi，不是訪客網路，手機沒有用行動數據。
  • 關掉電腦和手機的 VPN。
  • 確認防火牆有允許自在投影（見下方「防火牆」）。
  • 學校、公司、飯店的網路可能封鎖裝置探索，換個網路試試。
  • 同一台電腦只能有一個 AirPlay 接收程式；若有 AirServer、UxPlay、LonelyScreen 等，請先關閉。
  • 把手機的 Wi-Fi 關掉再打開，或重新開啟自在投影。
有畫面，但沒有聲音
  • 按 iPhone 的音量鍵調大聲一點，並確認 iPhone 側邊的靜音開關沒有打開（部分 App 在靜音模式下不出聲）。
  • 檢查電腦右下角的音量，以及「音量混合程式」裡自在投影沒有被調成靜音。
  • 確認 Windows 的預設輸出裝置是你正在聽的喇叭或耳機。換了耳機後，可以重新連線一次。
  • 有些 App（例如部分影音平台）為了版權保護，不允許在螢幕鏡像時輸出畫面或聲音，這不是自在投影的問題。
畫面有延遲、會卡
  • Wi-Fi 訊號是最大的影響因素。手機和電腦都盡量連 5 GHz 的 Wi-Fi，靠近分享器，電腦可以改用網路線。
  • 暫時把畫質調到「標準」。
  • 關閉正在大量下載或上傳的程式（雲端同步、遊戲更新等）。
  • 一般操作會有很短的延遲是正常的；看影片時畫面和聲音都會一起傳送。
畫面糊糊的、不夠清楚
  • 右鍵選單 → 設定 → 畫質，改成「高」或「最高」。若是灰色無法選，請安裝 Microsoft Store 的「HEVC 影片延伸模組」。
  • 變更畫質後，下一次連線才會生效（正在投影時會等手機中斷）。
  • 網路不穩時，手機會自動降低畫質，畫面暫時變模糊是正常的。
投影到一半被別人的手機接手了
  • 右鍵選單 → 設定 → 新手機連線時，改成「保持目前」，正在投影時其他手機就連不進來。
  • 也可以同時開啟「連線需要 PIN 碼」，沒輸入過 PIN 的手機都無法投影。
防火牆：當初按了「取消」怎麼辦？
  1. 開始 → 搜尋「允許應用程式通過 Windows 防火牆」並打開。
  2. 按變更設定，在清單中找到「自在投影」，勾選私人（在公用網路使用的話，也勾公用）。
  3. 清單裡找不到的話，按允許其他應用程式…，選安裝資料夾中的「自在投影.exe」。
  4. 若有安裝其他防毒軟體的防火牆，也要在那裡允許自在投影。

另外，Windows 若把你家的網路設成「公用網路」，限制會比較多。可以在 設定 → 網路和網際網路 → Wi-Fi → 你的網路 中改成「私人網路」。

開了 VPN 就連不上

VPN 會把網路流量導到別的地方，手機和電腦就不在「同一個網路」了。投影時請先中斷電腦與手機上的 VPN。有些 VPN 提供「允許區域網路存取（Local network sharing／LAN access）」選項，開啟後也可以一起使用。

Android 投放（Miracast）連不上
  • 先用 netsh wlan show drivers 確認電腦支援「Wireless Display」（見第 3 節）。
  • 電腦的 Wi-Fi 要開著，而且不要同時開「行動熱點」。
  • 一直停在「正在連線」：在手機上取消，等 10 秒後再試一次；或把手機的 Wi-Fi 關掉再打開。
  • 部分電腦的網卡雖然支援，但和某些手機相容性不佳。可以更新 Wi-Fi 網卡驅動程式，或改用方式二：無線偵錯。
  • Google Pixel 不支援 Miracast，請直接使用方式二。
無線偵錯一直斷線、或下次沒有自動連上
  • 手機重新開機或切換 Wi-Fi 後，無線偵錯常被系統自動關閉。回到開發人員選項把它重新打開即可，不用重新配對。
  • 手機的省電模式可能在螢幕關閉後中斷 Wi-Fi。可以在電池設定中把省電模式關掉，或把「設定」排除在電池最佳化之外。
  • 確認手機和電腦仍在同一個網路，且沒有開 VPN。
  • 還是不行：在手機的「已配對的裝置」中移除這台電腦，再用「連接 Android（掃 QR）」重新配對一次。
  • 用工具列或 CtrlD 中斷過的手機，不會自動重新連上；用「連接 Android（掃 QR）」再連一次，或重新開啟自在投影即可恢復。
找不到「中斷連線」在哪裡

把滑鼠移到投影畫面上，上方中央會出現工具列，最右邊的紅色按鈕就是中斷連線。也可以按 CtrlD，或在右下角系統匣圖示按右鍵 →中斷連線（手機名稱）。Android 畫面上按右鍵是「返回」，所以右鍵不會出現選單；要選單請點工具列的「更多」。

關掉視窗後，程式還在執行嗎？

是的，它在右下角系統匣待命。要完全結束，請在系統匣圖示上按右鍵 → 結束。不想開機自動執行，可以取消「開機自動啟動」。
