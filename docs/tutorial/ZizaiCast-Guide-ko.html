Zizai Cast · 사용 가이드

휴대폰 화면을
PC에서 크게.

iPhone, iPad, Android 휴대폰 화면을 이 Windows PC로 미러링할 수 있습니다. 먼저 1장에서 네트워크를 확인한 다음, 사용하는 휴대폰에 맞는 장으로 이동하세요.

iPhone · iPad화면 미러링제어 센터에서 한 번만 누르면 화면과 소리가 함께 나옵니다. Android 방법 1화면 전송(Miracast)설정이 필요 없지만 PC가 무선 디스플레이를 지원해야 합니다. Android 방법 2무선 디버깅처음 한 번만 설정하면 마우스로 휴대폰을 조작할 수 있습니다.

1시작하기 전에

휴대폰은 네트워크를 통해 PC를 찾습니다. ‘Zizai Cast가 안 보여요’ 같은 문제는 대부분 이 장의 내용 때문입니다.

  1. 같은 Wi-Fi·같은 네트워크. 휴대폰의 Wi-Fi와 PC가 같은 공유기에 연결되어 있어야 합니다. PC가 그 공유기에 유선으로 연결되어 있어도 괜찮습니다. 휴대폰의 모바일 데이터나 핫스팟으로는 안 됩니다.
  2. 처음 실행할 때 방화벽 허용. Zizai Cast를 실행했을 때 ‘Windows 보안 경고’가 나타나면 개인 네트워크에 체크하고 액세스 허용을 클릭하세요. 취소를 눌렀다면 자주 묻는 질문을 참고하세요.
  3. VPN은 끄기. PC나 휴대폰에서 VPN을 쓰면 통신이 다른 네트워크로 돌아가서 휴대폰이 PC를 찾지 못합니다. 미러링하는 동안에는 VPN을 꺼 주세요.
  4. 학교·회사·호텔 네트워크에서는 안 될 수 있습니다. 기기끼리의 통신을 막아 두는 경우가 많아, 같은 Wi-Fi여도 서로 보이지 않습니다. ‘게스트 네트워크’도 마찬가지입니다. 집 네트워크를 쓰거나 PC의 모바일 핫스팟에 휴대폰을 연결하세요.
화면에서 사라졌나요? 창을 닫아도 앱은 종료되지 않습니다. 백그라운드에서 대기합니다(작업 표시줄의 알림 영역, 시계 옆 작은 아이콘). 계속 연결을 기다리며, 휴대폰이 연결되면 창이 자동으로 다시 나타납니다.

대기 화면: 휴대폰을 선택하세요

아직 연결된 휴대폰이 없으면 창에 휴대폰을 선택하세요가 표시되고 아래에 카드 세 장이 나타납니다. 휴대폰 종류에 맞는 카드의 버튼을 누르면 됩니다.

카드이럴 때버튼
iPhone / iPad휴대폰의 제어 센터 → 화면 미러링에서 Zizai Cast를 선택합니다.단계 보기(2장)
Android 보기만휴대폰의 캐스트 / Smart View로 화면만 봅니다. 조작은 할 수 없습니다(Miracast).단계 보기(3장)
Android PC로 조작무선 디버깅을 사용하며, PC의 마우스와 키보드로 휴대폰을 조작할 수 있습니다.QR 표시(QR 코드로 페어링, 4장)

카드 옆에 회색 작은 글씨(예: ‘재부팅 후 사용 가능’)가 보이면 그 방법을 지금은 쓸 수 없는 이유를 알려 주는 것입니다. 카드의 연결 방법을 누르면 이 안내서가 열립니다(도움말 메뉴의 첫 항목 연결 방법도 같습니다).

2iPhone / iPad

Apple의 기본 기능인 ‘화면 미러링’을 사용하므로 앱을 설치할 필요가 없습니다. 화면과 소리가 함께 PC로 전송됩니다.

미러링 시작

  1. PC에서 Zizai Cast가 실행 중인지 확인합니다(창에 ‘휴대폰 연결 대기 중…’이 표시되거나 알림 영역에 아이콘이 있음).
  2. iPhone에서 제어 센터를 엽니다. Face ID 모델은 화면 오른쪽 위에서 아래로, 홈 버튼이 있는 모델은 화면 아래에서 위로 쓸어 올립니다.
  3. 화면 미러링을 누릅니다.
  4. 목록에서 Zizai Cast를 선택합니다. 몇 초 안에 iPhone 화면이 PC에 나타납니다.

미러링 중지

다시 제어 센터 → 화면 미러링 → 미러링 중단을 누르면 PC는 대기 화면으로 돌아갑니다. PC에서도 끊을 수 있습니다(연결 끊는 방법).

PIN과 여러 대의 휴대폰

  • 오른쪽 클릭 메뉴 → 설정(알림 영역 메뉴에도 있음)에서 새 휴대폰은 PIN으로 연결을 켜면, 처음 연결하는 iPhone은 PC에 표시되는 4자리 PIN을 입력해야 미러링할 수 있습니다. 한 번 성공한 iPhone은 기억됩니다.
  • 다른 iPhone도 Zizai Cast를 선택했을 때의 동작은 오른쪽 클릭 메뉴 → 설정 → 두 번째 휴대폰이 연결되면에서 고릅니다: 새 휴대폰으로 전환(기본, 새 휴대폰 화면 표시) / 지금 휴대폰 유지(먼저 연결된 휴대폰 유지).
  • iPhone 화면이 꺼지면 미러링이 일시 정지되고, 잠금을 해제하면 자동으로 계속됩니다.
  • iPhone의 음량 버튼으로 PC에서 나오는 소리 크기를 조절할 수 있습니다.

3Android 방법 1: 화면 전송(Miracast)

많은 Android 휴대폰에는 무선 화면 전송(Miracast) 기능이 들어 있습니다. 설정은 필요 없지만 화면을 보기만 할 수 있고 PC에서 휴대폰을 조작할 수는 없습니다. 또한 PC의 Wi-Fi 어댑터가 지원해야 합니다.

화면 전송 시작

  1. PC에서 Zizai Cast가 실행 중이고 PC의 Wi-Fi가 켜져 있는지 확인합니다(인터넷은 유선이어도 Wi-Fi 어댑터는 켜 두어야 합니다).
  2. 휴대폰 화면 위쪽에서 두 번 아래로 쓸어내려 빠른 설정 창을 모두 열고, 화면 전송 버튼을 찾습니다. Samsung Galaxy는 Smart View, 다른 기기는 화면 전송, 미러링 등으로 표시됩니다. 없으면 빠른 설정의 편집(연필 아이콘)에서 추가합니다.
  3. 검색된 기기 목록에서 Zizai Cast를 선택합니다(PC 이름으로 표시되는 기기도 있습니다). 처음에는 10~20초 걸릴 수 있습니다.
  4. 중지하려면 같은 버튼을 다시 누릅니다. PC에서는 도구 모음의 연결 끊기 또는 CtrlD.

Google Pixel은 Miracast를 지원하지 않습니다(Pixel의 ‘전송’은 Chromecast 전용). 방법 2: 무선 디버깅을 사용하세요.

PC 지원 여부 확인

시작 버튼을 오른쪽 클릭 → 터미널을 열고, 다음 줄을 입력한 뒤 Enter를 누릅니다.

netsh wlan show drivers

결과에 무선 디스플레이 지원: 예(영어 표시에서는 Wireless Display Supported: Yes)가 있고 그래픽 드라이버와 Wi-Fi 드라이버가 모두 ‘예’이면 사용할 수 있습니다. ‘아니요’이면 드라이버를 업데이트하거나 방법 2를 사용하세요.

4Android 방법 2: 무선 디버깅

Android의 기본 기능인 ‘무선 디버깅’으로 연결합니다. 처음에 몇 분 정도 설정이 필요하지만, 그다음부터는 자동으로 연결되고 PC의 마우스와 키보드로 휴대폰을 조작할 수 있습니다. Android 11 이상이 필요하며, 휴대폰과 PC는 같은 네트워크에 있어야 합니다(1장).

1단계: 개발자 옵션 켜기

  1. 휴대폰의 설정 → 휴대전화 정보를 엽니다.
  2. 빌드 번호를 7번 연속으로 누릅니다. ‘개발자 모드를 사용하도록 설정했습니다’ 같은 메시지가 나오면 됩니다(잠금 해제 비밀번호를 물어볼 수 있습니다).
  3. 설정에 개발자 옵션이 생깁니다(대개 ‘시스템’ 안이나 설정 맨 아래).

Samsung Galaxy: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호. 개발자 옵션은 설정 맨 아래에 있습니다.

2단계: 페어링(처음 한 번만)

  1. 휴대폰: 개발자 옵션 → 무선 디버깅 스위치를 켭니다(처음에는 ‘이 네트워크에서 무선 디버깅을 허용하시겠습니까?’라고 물으면 허용).
  2. PC: Zizai Cast 창을 오른쪽 클릭 → 휴대폰 연결 → Android 연결(QR 스캔)(대기 화면의 ‘Android PC로 조작’ 카드에도 QR 표시 버튼이 있음). QR 코드가 나타납니다.
  3. 휴대폰: ‘무선 디버깅’ 글자를 눌러 페이지를 열고 → QR 코드로 기기 페어링 → PC의 QR 코드를 스캔합니다.
  4. 페어링이 끝나면 창이 자동으로 닫히고 휴대폰 화면이 PC에 나타납니다.
‘휴대폰에서 스캔하기를 기다리는 중…’에서 멈춰 있다면 약 45초 동안 휴대폰의 응답이 없으면 안내가 표시됩니다. 휴대폰과 PC가 같은 Wi-Fi(게스트 Wi-Fi 아님)인지 확인하거나 페어링 코드 사용을 클릭하세요. 휴대폰에서 ‘페어링 코드로 기기 페어링’을 누르고, 표시된 IP 주소:포트와 6자리 코드를 PC에 입력한 뒤 페어링을 클릭합니다.

다음부터는 자동 연결

페어링한 휴대폰은 무선 디버깅이 켜져 있고 PC와 같은 네트워크에 있으면 자동으로 연결됩니다. 다시 시작하거나 Wi-Fi를 바꾸면 무선 디버깅이 꺼지는 기기가 많은데, 그때는 다시 켜기만 하면 됩니다(다시 페어링할 필요 없음).

오른쪽 클릭이 ‘뒤로’라면 메뉴는 어디에? Android 화면에서는 오른쪽 클릭이 휴대폰의 뒤로가 됩니다. 메뉴를 열려면 마우스를 화면 위쪽으로 옮겨 도구 모음의 더 보기(전체 메뉴)를 클릭하거나, Shift를 누른 채 오른쪽 클릭하세요(Shift+오른쪽 클릭은 항상 메뉴를 엽니다). 오른쪽 클릭으로 메뉴를 열고 싶다면 설정 → 오른쪽 클릭 동작을 메뉴 열기로 바꾸세요(기본값은 뒤로). 메뉴 열기로 바꾸면 ‘뒤로’는 도구 모음의 버튼을 사용합니다.

5기능과 단축키

미러링 중에 화면 위로 마우스를 움직이면 위쪽에 도구 모음이 나타납니다. 창을 오른쪽 클릭하면 모든 기능을 쓸 수 있습니다(Android 화면에서 오른쪽 클릭은 기본적으로 ‘뒤로’이므로 도구 모음의 ‘더 보기’ 또는 Shift+오른쪽 클릭, 또는 설정 → 오른쪽 클릭 동작을 메뉴 열기로 변경). 단축키가 기억나지 않으면 F1(또는 도움말 → 단축키 목록)을 누르세요. 단축키는 창을 한 번 클릭한 뒤에 사용하세요. 표시 언어는 설정 → 언어 / Language에서 바꿉니다: 자동(Windows 언어 따름), 繁體中文, English, 日本語, 한국어.

도구 모음

마우스를 움직이면 화면 위쪽 가운데에 나타나고, 2초쯤 움직이지 않으면 숨겨집니다. 왼쪽부터 (Android만: 뒤로, 홈, 최근 앱) 스크린샷, 녹화, 휴대폰으로 보내기, 회전, 전체 화면, 돋보기, 번역, 화면 정지, 더 보기, 연결 끊기. 자주 쓰는 네 개(스크린샷, 녹화, 번역, 돋보기)는 글자 이름이 함께 표시되고, 나머지 버튼은 마우스를 올리면 이름과 단축키가 표시됩니다. 처음 연결할 때 도구 모음 위치를 한 번 알려 줍니다.

휴대폰이 연결되기 전에는 오른쪽 클릭 메뉴의 스크린샷, 녹화 시작, 돋보기 등도 회색으로 표시되고 오른쪽에 휴대폰 연결 후 사용 가능이라고 나옵니다(연결되면 누를 수 있습니다).

연결 끊는 방법

iPhone, Android 화면 전송, 무선 디버깅 모두 같습니다.

  1. 도구 모음 오른쪽 끝의 빨간 연결 끊기 버튼.
  2. CtrlD 누르기.
  3. 오른쪽 클릭 메뉴(또는 도구 모음의 ‘더 보기’) 맨 위의 연결 끊기.
  4. 알림 영역 아이콘을 오른쪽 클릭 → 연결 끊기(휴대폰 이름). 창이 백그라운드에서 대기 중일 때도 쓸 수 있습니다.

녹화 중이면 먼저 녹화를 멈추고 저장합니다. PC에서 연결을 끊은 Android 휴대폰은 자동으로 다시 연결되지 않습니다(휴대폰 연결 → Android 연결(QR 스캔)으로 다시 연결하거나 Zizai Cast를 다시 시작하세요).

스크린샷 CtrlS

설치 폴더의 ‘截圖’(스크린샷) 폴더에 ‘ZizaiCast_날짜_시간.png’ 같은 이름으로 저장됩니다. 오른쪽 클릭 메뉴 → 스크린샷 폴더 열기.

녹화 CtrlR

한 번 더 누르면 중지. 소리가 포함된 MP4로 ‘錄影’(녹화) 폴더에 저장됩니다. 폴더는 메뉴 최상위의 녹화 폴더 열기로 엽니다.

전체 화면 F11

화면을 두 번 클릭해도 됩니다. Esc로 나갑니다.

항상 위에 표시 CtrlT

미러링 창을 다른 창보다 항상 위에 둡니다.

회전·반전

Ctrl→ / Ctrl←로 90° 회전, CtrlH로 좌우 반전, Ctrl0으로 원래대로.

테마·화질

테마: 벚꽃, 민트, 밤하늘, 밀크티(설정 → 테마). 화질은 설정 → 화질(표준(부드러움) / 높음(권장) / 최고(네트워크 많이 사용)). 화질이 높을수록 Wi‑Fi 부담이 커지니, 끊기면 ‘표준’을 고르세요. 화질이나 PIN을 바꾸면 기본적으로 이번 미러링이 끝난 뒤에 적용되며, 안내 옆의 지금 다시 연결해 적용을 누르면 바로 다시 연결해 적용됩니다(iPhone은 휴대폰에서 화면 미러링을 다시 선택).

백그라운드 대기와 알림 영역

창을 닫으면 ‘Zizai Cast를 종료할까요, 아니면 백그라운드에서 대기할까요?’라고 묻습니다. 백그라운드에서 대기를 고르면 알림 영역에서 계속 휴대폰을 기다립니다(‘이 선택 기억하기’ 후에는 설정 → 창을 닫을 때에서 변경). Windows 11에서는 아이콘이 ‘^’ 안에 숨어 있을 수 있으니 작업 표시줄로 끌어다 놓으면 항상 표시됩니다. 완전히 종료하려면 아이콘을 오른쪽 클릭 → 종료.

돋보기·고대비·화면 정지

휴대폰 글자가 작아서 잘 안 보이면 화면을 오른쪽 클릭(Android 화면에서는 도구 모음의 ‘더 보기’ 또는 Shift+오른쪽 클릭) → 돋보기. 휴대폰 화면이 표시될 때 사용할 수 있습니다.

확대·축소 Ctrl= Ctrl-

최대 8배까지. Ctrl을 누른 채 마우스 휠을 돌리면 마우스가 가리키는 곳을 확대합니다. 1×로 되돌리기: CtrlShift0.

확대한 화면 이동

마우스로 드래그합니다(PC에서 Android 휴대폰을 조작 중일 때는 Ctrl을 누른 채 드래그). 오른쪽 아래의 작은 전체 화면 지도에서 지금 보고 있는 위치를 알 수 있습니다.

도구 모음의 돋보기 버튼

클릭할 때마다 1× → 2× → 4× → 1×로 바뀝니다.

고대비 CtrlK

눈이 불편한 분을 위한 색상: 원래 색, 대비 강화, 회색조, 색 반전, 검은 바탕에 노란 글자. 고른 색상은 다음에도 그대로 유지됩니다.

화면 정지 CtrlP

PC 화면만 멈춰서 천천히 읽을 수 있고, 휴대폰은 그대로 쓸 수 있습니다. 한 번 더 누르면 다시 움직입니다. 도구 모음에도 버튼이 있습니다. 녹화는 휴대폰의 실시간 화면을 계속 기록합니다.

화면의 글자 번역하기

읽을 수 없는 영어·일본어·중국어가 보이면 화면을 오른쪽 클릭 → 번역, 또는 도구 모음의 번역 버튼을 누르세요. 번역문은 원래 글자 위에 작은 카드로 표시됩니다.

메뉴하는 일
화면 전체 번역 CtrlL보이는 화면 전체를 번역합니다. CtrlL을 한 번 더 누르면 번역을 닫습니다.
선택 영역 번역 CtrlShiftL마우스로 상자를 그린 부분만 번역합니다(Esc로 취소).
원문 보기 CtrlO번역을 잠시 숨기고 원래 글자를 봅니다. 번역 전에는 회색이며 ‘먼저 ‘화면 전체 번역’을 누르세요’라고 안내합니다.
실시간 번역화면이 바뀌어도 자동으로 다시 번역합니다. 스크롤하면서 읽을 때 편리합니다.
번역할 언어繁體中文, English, 日本語, 한국어 중에서 고릅니다(번역 메뉴 첫 단계에 있음).
표시 방법자동 / 원래 위치에 표시(작은 카드를 원문 위에) / 목록으로 표시. 어두운 상자(읽기 쉬움)로 글자를 더 읽기 쉽게 할 수 있습니다.
고급 번역 설정(번역 ▸ 고급 번역 설정 ▸ …) 평소에는 바꾸지 않아도 됩니다(오프라인 번역만으로 사용 가능). 로컬 AI 번역…, 온라인 번역(선택)…, 번역 모델 관리(다운로드한 번역 모델 확인·삭제)가 들어 있습니다.
오프라인 번역: 화면의 글자는 인터넷으로 전송되지 않습니다 글자는 Windows에 내장된 텍스트 인식(OCR)으로 읽고, 번역도 이 PC 안에서 합니다. 어떤 언어를 처음 번역할 때는 먼저 확인을 받은 뒤 번역 모델을 한 번만 다운로드합니다(Mozilla Firefox Translations, MPL-2.0 라이선스. 번역 방향 하나에 약 50MB, 영어를 거치는 조합은 두 개가 필요해 약 100MB). 저장 위치는 %LOCALAPPDATA%\PhoneMirror\models입니다. 번역할 수 있는 원문: 영어, 일본어, 한국어, 중국어.

일본어 등이 번역되지 않으면 Windows가 아직 그 글자를 읽지 못하는 것일 수 있습니다. 추가 방법 안내와 언어 설정 열기 버튼이 표시됩니다(자주 묻는 질문).

휴대폰으로 보내기

스크린샷이나 녹화가 끝나면 화면 아래에 휴대폰으로 보내기 버튼이 나타납니다. 클릭하면 파일을 휴대폰으로 보낼 수 있습니다. 오른쪽 클릭 메뉴의 휴대폰으로 보내기 ▸ 마지막 스크린샷을 휴대폰으로 보내기, 마지막 녹화를 휴대폰으로 보내기, 휴대폰으로 보내기…(파일 직접 선택)나 도구 모음의 버튼으로도 보낼 수 있습니다.

  • 무선 디버깅으로 연결된 Android: 휴대폰 갤러리에 바로 저장됩니다. 따로 할 일은 없습니다.
  • iPhone / iPad, Android 화면 전송(Miracast): PC에 QR 코드가 나타나면 휴대폰 카메라로 스캔하세요. 휴대폰에서 페이지가 열리면, 사진은 길게 터치 → ‘사진 앱에 저장’(iPhone) / ‘이미지 다운로드’(Android), 동영상은 ‘동영상 다운로드’를 누르고 페이지의 안내를 따릅니다.
  • 휴대폰은 PC와 같은 Wi-Fi에 연결되어 있어야 합니다. 링크는 10분 동안만 유효하며 QR 코드를 스캔한 사람만 열 수 있습니다. 공유 중지로 일찍 끝낼 수 있습니다.

자동 업데이트

Zizai Cast는 실행할 때마다 새 버전이 있는지 확인합니다(실행 중에는 6시간마다). 메뉴의 업데이트 확인으로도 확인할 수 있습니다. 설치 폴더 안의 ‘安裝檔’(설치 파일) 폴더에 넣은 새 설치 파일도 자동으로 찾아냅니다.

새 버전이 있으면 ‘Zizai Cast 새 버전’ 창이 열리고, 새로운 기능과 버튼 세 개가 표시됩니다.

버튼동작
지금 업데이트새 버전을 설치합니다. Zizai Cast가 종료되고 업데이트된 후 자동으로 다시 열립니다.
나중에 알림지금은 업데이트하지 않고 나중에 다시 알려 줍니다.
이 버전 건너뛰기이 버전은 더 이상 알리지 않습니다(메뉴에서는 계속 업데이트 가능).

저절로 업데이트되거나 미러링을 중단하는 일은 없습니다. 나중에 업데이트하려면 메뉴 맨 위 등에 나타나는 vX.Y.Z(으)로 업데이트를 클릭하세요. 녹화 중이면 먼저 물어보고 녹화를 저장합니다.

6자주 묻는 질문

질문을 클릭하면 답이 펼쳐집니다.

휴대폰 목록에 ‘Zizai Cast’가 나오지 않아요
  • Zizai Cast가 실행 중인지(알림 영역에 아이콘이 있는지) 확인하세요.
  • 휴대폰과 PC가 같은 Wi-Fi(게스트 네트워크 아님)에 연결되어 있고, 휴대폰이 모바일 데이터를 쓰고 있지 않은지 확인하세요.
  • PC와 휴대폰의 VPN을 끄고, 방화벽에서 허용되어 있는지도 확인하세요(아래 ‘방화벽’).
  • AirServer, UxPlay 같은 다른 AirPlay 수신 프로그램이 실행 중이면 종료하세요.
  • 휴대폰의 Wi-Fi를 껐다 켜거나 Zizai Cast를 다시 시작해 보세요.
화면은 나오는데 소리가 안 나요
  • iPhone의 음량 버튼으로 소리를 키우고, 무음 모드(벨소리/무음 스위치)가 아닌지 확인하세요.
  • PC의 음량과, 볼륨 믹서에서 Zizai Cast가 음소거되어 있지 않은지 확인하세요.
  • 일부 동영상 앱은 저작권 보호 때문에 화면 미러링 중에 화면이나 소리를 내보내지 않습니다. Zizai Cast의 문제가 아닙니다.
화면이 늦거나 끊겨요
  • 휴대폰과 PC 모두 공유기 가까이에서 5GHz Wi-Fi를 쓰거나, PC를 유선으로 연결하세요.
  • 화질을 잠시 ‘표준(부드러움)’으로 바꾸고, 대용량 다운로드 중인 프로그램을 닫으세요.
화면이 흐려요

오른쪽 클릭 메뉴 → 설정 → 화질에서 ‘높음(권장)’이나 ‘최고(네트워크 많이 사용)’를 고르세요. 선택할 수 없으면 Microsoft Store에서 ‘HEVC 비디오 확장’을 설치하세요. 변경 사항은 기본적으로 다음 연결부터 적용되며, 바로 적용하려면 안내 옆의 지금 다시 연결해 적용을 누르세요.

미러링 중에 다른 사람의 휴대폰으로 바뀌었어요

오른쪽 클릭 메뉴 → 설정 → 두 번째 휴대폰이 연결되면 → 지금 휴대폰 유지를 고르세요. 새 휴대폰은 PIN으로 연결을 켜는 것도 좋습니다.

방화벽 경고에서 ‘취소’를 눌렀어요
  1. 시작 → ‘Windows 방화벽을 통해 앱 허용’을 검색해서 엽니다.
  2. 설정 변경을 클릭하고, 목록의 ‘Zizai Cast’(自在投影)에서 개인에 체크합니다.
  3. 목록에 없으면 다른 앱 허용에서 설치 폴더의 程式\自在投影.exe를 선택합니다.
VPN을 켜면 연결이 안 돼요

VPN은 통신을 다른 곳으로 돌리기 때문에 휴대폰과 PC가 ‘같은 네트워크’가 아니게 됩니다. 미러링 중에는 PC와 휴대폰의 VPN을 꺼 주세요. ‘로컬 네트워크 접근 허용’ 옵션이 있는 VPN이라면 그 옵션을 켜고 함께 쓸 수 있습니다.

Android 화면 전송(Miracast)이 연결되지 않아요
  • netsh wlan show drivers로 PC가 무선 디스플레이를 지원하는지 확인하세요(3장).
  • PC의 Wi-Fi는 켜고, 모바일 핫스팟은 끄세요.
  • ‘연결 중’에서 멈추면 휴대폰에서 취소하고 10초 뒤에 다시 시도하세요.
  • 그래도 안 되면 방법 2: 무선 디버깅을 사용하세요.
무선 디버깅이 자꾸 끊기거나 다음에 자동으로 연결되지 않아요
  • 다시 시작하거나 Wi-Fi를 바꾸면 무선 디버깅이 꺼질 수 있습니다. 개발자 옵션에서 다시 켜세요(다시 페어링할 필요 없음).
  • 휴대폰의 절전 모드가 화면이 꺼졌을 때 Wi-Fi를 끊을 수 있습니다.
  • 그래도 안 되면 휴대폰의 ‘페어링된 기기’에서 이 PC를 삭제하고 휴대폰 연결 → Android 연결(QR 스캔)으로 다시 페어링하세요.
‘연결 끊기’를 찾을 수 없어요

미러링 화면 위로 마우스를 움직이면 위쪽 가운데에 도구 모음이 나타납니다. 오른쪽 끝의 빨간 버튼이 연결 끊기입니다. CtrlD로도 끊을 수 있습니다.

번역이 안 되거나 일본어·중국어 글자를 인식하지 못해요
  • 처음 번역할 때는 번역 모델을 다운로드해야 합니다: 확인 창이 나오면 다운로드를 클릭하세요(한 번만, 번역 방향 하나에 약 50MB). 나중에를 고르면 번역되지 않고, 다음 번역 때 다시 묻습니다.
  • 글자를 인식하지 못할 때: Windows에 그 언어의 ‘광학 문자 인식’을 추가해야 합니다. 안내 창의 언어 설정 열기를 클릭하거나, Windows 설정 → 시간 및 언어 → 언어 및 지역 → 언어 추가 → 일본어(등) → 다음으로 가서 ‘광학 문자 인식’만 선택하고(표시 언어나 언어 팩은 필요 없음) 설치하세요. 설치가 끝나면 다시 번역하세요.
  • 다운로드한 번역 모델은 번역 → 번역 모델 관리에서 확인하고 삭제할 수 있습니다.
