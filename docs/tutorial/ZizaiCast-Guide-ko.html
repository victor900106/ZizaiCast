Zizai Cast에는 두 가지 기능이 있습니다. 휴대폰 미러링은 휴대폰 화면을 이 PC에 띄우고, 원격 제어는 반대로 휴대폰으로 이 PC를 조작합니다. 모든 장은 “하고 싶은 일 → 몇 단계 → 성공하면 보이는 것 → 안 될 때”의 순서로 쓰여 있습니다. 아래 표에서 바로 이동하세요.

0시작하기 전에

휴대폰은 네트워크로 PC를 찾습니다. “Zizai Cast가 안 보여요”는 대부분 아래 중 하나입니다.

  1. 휴대폰과 PC를 같은 Wi-Fi에. PC가 같은 공유기에 랜선으로 연결되어 있어도 됩니다. 모바일 데이터, 핫스폿, 게스트 Wi-Fi는 안 됩니다.
  2. 처음에 방화벽 허용. “Windows 보안 경고”가 나오면 개인 네트워크를 선택하고 액세스 허용. 취소를 눌렀다면 여기.
  3. VPN은 끄기. PC나 휴대폰에서 VPN이 켜져 있으면 휴대폰에서 PC가 안 보이는 경우가 많습니다.

Zizai Cast를 열면

창 위쪽에 휴대폰 미러링과 원격 제어 두 탭이 있습니다. 휴대폰 미러링 탭에는 사용하는 휴대폰을 선택하세요와 카드 3장이 있으니, 내 휴대폰 카드의 버튼을 누르면 됩니다.

창을 닫아도 종료되지 않습니다. 앱 종료와 백그라운드에서 대기 중에서 고르라고 묻습니다. 대기를 고르면 오른쪽 아래 시계 옆 아이콘이 되고, 휴대폰이 연결되면 창이 다시 나타납니다.

1iPhone 미러링

하고 싶은 일iPhone / iPad 화면과 소리를 PC로. 앱 설치는 필요 없습니다.

  1. PC에서 Zizai Cast가 실행 중(창 또는 오른쪽 아래 아이콘).
  2. iPhone에서 제어 센터 열기: Face ID 모델은 오른쪽 위에서 아래로, 홈 버튼이 있는 모델은 아래에서 위로 쓸어내리기.
  3. 화면 미러링(사각형 두 개가 겹친 아이콘) 누르기.
  4. 목록에서 Zizai Cast 누르기.
성공하면 이렇게 보입니다몇 초 안에 PC에 휴대폰 화면이 나오고 “연결됨: 휴대폰 이름… 위쪽에 도구 모음이 있습니다”가 표시됩니다. 처음 연결하면 도구 모음에 “자주 쓰는 기능은 이 도구 모음에 있어요(캡처·녹화·번역·확대). 마우스를 화면 위쪽으로 가져가면 나타나고, 포인터를 올려 두는 동안에는 사라지지 않아요.”가 나옵니다. 도구 모음이 숨어 있을 때는 화면 맨 위의 분홍색 가는 선이 위치를 알려 줍니다.
안 될 때
  • 목록에 “Zizai Cast”가 없음: Zizai Cast가 안 보여요.
  • 화면은 나오는데 소리가 없음: iPhone 음량 버튼으로 올리기. 소리 크기 참고.
  • 4자리 PIN을 물음: PC에 나온 숫자를 iPhone에 입력(설정에서 새 휴대폰은 PIN으로 연결을 켰을 때만).

미러링 끝내기

iPhone 제어 센터 → 화면 미러링 → 미러링 중단. 또는 PC에서 CtrlD, 도구 모음 오른쪽 끝의 빨간 연결 끊기. iPhone을 잠그면 화면이 잠시 멈추고, 잠금을 풀면 자동으로 이어집니다.

연결을 끊는 네 곳(iPhone, Android 모두 같음): 도구 모음 오른쪽 끝 빨간 버튼, CtrlD, 오른쪽 클릭 메뉴 맨 위 연결 끊기, 오른쪽 아래 아이콘을 오른쪽 클릭 → 연결 끊기(휴대폰 이름). 녹화 중이면 먼저 저장됩니다.

2Android 화면 전송(Miracast)

하고 싶은 일Android 화면을 PC에 띄워 보기만 합니다. 설정은 필요 없지만, PC에 “무선 디스플레이”를 지원하는 Wi-Fi 어댑터가 있어야 합니다(대부분의 노트북은 지원).

  1. Zizai Cast가 실행 중이고 PC의 Wi-Fi가 켜져 있음(랜선으로 인터넷을 써도 켜 두기).
  2. 휴대폰에서 위에서 아래로 두 번 쓸어내리고 전송 타일 찾기: Samsung은 Smart View, Xiaomi는 전송, OPPO는 화면 전송, vivo는 화면 미러링.
  3. 목록에서 Zizai Cast 누르기. 처음에는 10~20초 걸릴 수 있습니다.
성공하면 이렇게 보입니다PC에 휴대폰 화면이 나오고 “연결됨”. 끝내려면 휴대폰에서 같은 타일을 다시 누르거나 PC에서 CtrlD.
안 될 때
  • “Android 화면 보기만” 카드가 회색이고 “이유 보기”가 있음: 이 PC는 Miracast를 받을 수 없습니다. 링크를 열거나 Android 조작을 쓰세요.
  • Google Pixel에는 Miracast가 없습니다(“전송”은 Chromecast 전용): Android 조작을 쓰세요.
  • “연결 중”에서 멈춤: 휴대폰에서 취소하고 10초 뒤 다시 하거나 Miracast가 연결되지 않아요.

3Android 조작(QR 페어링, USB)

하고 싶은 일PC에서 Android 화면을 보고 마우스와 키보드로 조작합니다. 처음에 약 5분 설정하면 그다음부터는 자동으로 연결됩니다. Android 11 이상이 필요합니다.

1단계: “개발자 옵션” 켜기(한 번만)

  1. 휴대폰: 설정 → 휴대전화 정보(Samsung은 이어서 소프트웨어 정보).
  2. 빌드 번호를 7번 누르기. 잠금 해제 비밀번호를 물을 수 있습니다.
  3. “개발자가 되었습니다”가 나오면 끝. 설정에 개발자 옵션이 생깁니다(보통 “시스템” 안이나 맨 아래).

PC의 페어링 창에도 같은 단계가 있습니다: ① 개발자 옵션을 아직 안 켰나요? 단계 보기. “빌드번호” 위치: Samsung은 휴대전화 정보 → 소프트웨어 정보, Xiaomi/Redmi는 내 기기 → 전체 사양 → OS 버전(또는 MIUI 버전)을 7번, Pixel은 휴대전화 정보 맨 아래. 개발자 옵션은 Samsung이 설정 맨 아래, Xiaomi가 추가 설정, Pixel이 시스템 안에 있습니다.

2단계: QR 코드로 페어링(한 번만)

  1. 휴대폰: 개발자 옵션 → 무선 디버깅 켜기. 물으면 허용.
  2. PC: 대기 화면의 “Android PC로 조작” 카드에서 QR 코드 표시(또는 오른쪽 클릭 메뉴 → 휴대폰 연결 → Android 연결(QR 스캔)).
  3. 휴대폰: “무선 디버깅” 글자를 눌러 들어가기 → QR 코드로 기기 페어링으로 PC의 QR 코드 스캔.
성공하면 이렇게 보입니다페어링 창이 저절로 닫히고 휴대폰 화면이 나오며 “연결됨: 휴대폰 이름. 위쪽에 도구 모음이 있습니다. 오른쪽 클릭 = 뒤로”. 이후에는 무선 디버깅이 켜져 있고 같은 Wi-Fi이면 자동으로 연결됩니다.
안 될 때
  • “휴대폰에서 스캔하기를 기다리는 중…”에서 멈춤: 휴대폰과 PC가 같은 Wi-Fi가 아닙니다(게스트 네트워크 불가). 페어링 코드 사용을 누르고 휴대폰에서 “페어링 코드로 기기 페어링”을 열어 IP 주소:포트와 6자리 코드를 PC에 입력하는 방법도 있습니다.
  • 페어링 실패: 창에 새 QR 코드가 나오니 휴대폰에서 “QR 코드로 기기 페어링”을 다시 눌러 스캔합니다.
  • 한동안 아무도 스캔하지 않음: QR 코드가 어두워지고 시간 초과가 나오며 “대기를 멈췄습니다. Wi-Fi와 “무선 디버깅”을 확인하고…”라고 표시됩니다. QR 코드 다시 만들기를 눌러 새 코드를 스캔하세요.
  • 재부팅 후 자동으로 연결되지 않음: Android는 휴대폰을 다시 시작하면 무선 디버깅을 끕니다. Zizai Cast가 한 번 “이전에 페어링한 휴대폰을 찾지 못했습니다. 휴대폰을 방금 다시 시작했다면 “개발자 옵션”에서 “무선 디버깅”을 다시 켠 뒤 시도하세요”라고 알려 줍니다. 개발자 옵션에서 다시 켜면 되고 다시 페어링할 필요는 없습니다.

Wi-Fi가 없나요? USB 케이블로

  1. 휴대폰: 개발자 옵션 → USB 디버깅 켜기.
  2. 케이블로 PC에 연결하고 “USB 디버깅을 허용하시겠습니까?”에서 이 컴퓨터에서 항상 허용을 선택하고 허용.
  3. PC: 오른쪽 클릭 메뉴 → 휴대폰 연결 → USB 케이블로 연결.
성공하면 이렇게 보입니다“USB로 연결하는 중…” 다음에 휴대폰 화면이 나옵니다.
안 될 때
  • “USB로 연결된 Android 휴대폰이 없습니다”: 데이터 전송이 되는 케이블로 바꾸고(충전 전용 케이블이 있음), USB 디버깅이 켜졌는지 확인, 뽑았다 다시 꽂기.
  • 허용을 묻지 않음: 알림을 내려 USB 용도를 “파일 전송”으로 바꾸고 다시 시도.

4녹화와 스크린샷

하고 싶은 일휴대폰 화면을 사진으로 찍거나 동영상(소리 포함 MP4)으로 녹화합니다. 휴대폰 화면이 나온 뒤에 쓸 수 있습니다.

  1. 휴대폰 화면 위쪽으로 마우스를 가져가면 도구 모음이 나옵니다.
  2. 스크린샷: 캡처(또는 CtrlS).
  3. 녹화: 녹화(또는 CtrlR). 왼쪽 위에 빨간 점과 초가 나옵니다. 멈추려면 한 번 더 누릅니다.
  4. 파일 찾기: 오른쪽 클릭 메뉴 → 스크린샷 폴더 열기 / 녹화 폴더 열기.
성공하면 이렇게 보입니다찍으면 “스크린샷을 ‘사진\截圖’에 저장했습니다”. 끝의 보기를 누르면 그 사진이 열립니다(8초 동안 표시되며, 포인터를 올려 두는 동안에는 사라지지 않음). 녹화를 멈추면 “녹화 저장됨: 파일 이름”. 아래에 작은 버튼 폴더 열기 · 휴대폰으로 보내기가 나옵니다.
안 될 때
  • 버튼이 회색이고 “휴대폰 연결 후 사용 가능”: 먼저 휴대폰 화면을 띄우세요.
  • 녹화가 안 됨: 디스크 여유 공간이 300 MB 미만입니다.
  • 녹화 중에 연결이 끊김: 거기까지 녹화된 부분은 자동 저장됩니다.

5펜

하고 싶은 일띄운 화면에 선, 화살표, 형광펜을 그려 설명합니다. 그림은 PC에만 있고 휴대폰에는 그려지지 않습니다.

  1. 화면 위쪽으로 마우스를 가져가고 도구 모음의 펜(또는 CtrlE).
  2. 왼쪽 버튼을 누른 채 드래그해 그립니다. 도구 모음이 도구(펜 → 형광펜 → 화살표), 색, 굵기, 실행 취소, 지우기로 바뀝니다.
  3. Esc(또는 CtrlE를 한 번 더)로 펜 끝내기(그림은 남습니다). CtrlShiftE로 모두 지우기.
성공하면 이렇게 보입니다“펜 모드: 화면을 드래그해 그리세요(Esc로 끝내기)”, 화면 둘레에 분홍색 테두리가 생기고 왼쪽 아래에 작게 “펜 모드 · Esc 또는 Ctrl+E로 끝내기”. 스크린샷과 녹화에는 기본으로 그림이 들어갑니다(오른쪽 클릭 메뉴 → 펜에서 변경).
안 될 때
  • Android 조작 중 그리면 휴대폰이 눌림: 펜 모드에서는 마우스로 휴대폰 조작이 멈춥니다. 휴대폰을 조작하기 전에 Esc 또는 CtrlE.
  • 잘못 그림: CtrlZ로 마지막 획 실행 취소.

6파일 끌어 놓기와 휴대폰으로 보내기

하고 싶은 일PC의 사진, 동영상, 문서나 방금 찍은 스크린샷을 휴대폰으로.

방법 1: 파일을 Zizai Cast 창으로 끌기

  1. 파일 탐색기에서 파일을 골라 Zizai Cast 창 위로 끕니다(아직 놓지 않기). 놓으면 무엇이 되는지 창에 표시됩니다.
  2. 놓습니다.
성공하면 이렇게 보입니다Android 조작 중: 휴대폰으로 바로 들어가고(.apk는 설치), “휴대폰으로 보냈습니다: 이름” 또는 “설치했습니다: 이름”. iPhone, Miracast, 휴대폰 미연결: PC에 QR 코드가 나오니 방법 2의 3단계처럼 스캔합니다.

방법 2: 휴대폰으로 보내기(QR 코드)

  1. 오른쪽 클릭 메뉴 → 휴대폰으로 보내기 → 마지막 스크린샷을 휴대폰으로 보내기(또는 휴대폰으로 보내기…로 파일 고르기). 도구 모음에도 같은 버튼이 있습니다.
  2. 새 파일이 여러 개면 보낼 것을 선택하고 N개 보내기.
  3. 휴대폰을 같은 Wi-Fi에 연결하고 카메라로 PC의 QR 코드를 스캔해 페이지를 엽니다. 사진: 길게 눌러 “사진에 추가”(iPhone) 또는 “이미지 다운로드”(Android). 동영상: “동영상 다운로드”.
성공하면 이렇게 보입니다휴대폰에 파일 목록 페이지가 열리고 사진첩에 저장할 수 있습니다.
안 될 때
  • 페이지가 안 열림: 휴대폰이 같은 Wi-Fi가 아닙니다(게스트 네트워크, 모바일 데이터 불가).
  • “파일만 놓을 수 있습니다(폴더 불가)”: 폴더 안의 파일을 골라 끌거나 먼저 zip으로 압축하세요.
  • 링크 만료: 링크는 10분간 유효합니다. 다시 보내세요.

7번역

하고 싶은 일휴대폰의 영어, 일본어, 중국어 등을 한국어로 바꿔 원문 위에 겹쳐 봅니다. 번역은 이 PC 안에서 하며, 화면의 글자는 인터넷으로 보내지지 않습니다.

  1. 휴대폰 화면이 나온 상태에서 도구 모음의 번역(또는 CtrlL).
  2. 처음에는 번역 모델(약 50 MB, 한 번만) 다운로드를 묻습니다. 다운로드.
  3. 다시 번역(또는 CtrlL)을 누르면 닫힙니다.
성공하면 이렇게 보입니다원문 자리에 번역문이 나옵니다. 번역 중에는 화면이 잠시 멈추지만(오른쪽 위 “번역 중 · 화면 일시 정지”, 도구 모음이 나와 있으면 그 아래로 이동) 정상입니다. 번역을 닫으면 돌아옵니다.
안 될 때
  • “텍스트가 이미 한국어입니다”: 번역할 것이 없습니다.
  • 일본어·한국어를 못 읽음: Windows에 그 언어의 “광학 문자 인식”이 필요합니다. 여기.
  • 일부만 번역: 오른쪽 클릭 메뉴 → 번역 → 영역 번역(CtrlShiftL)으로 상자를 그립니다.

돋보기: 글자가 작을 때

도구 모음의 확대를 한 번 누르면 2배, 다시 누르면 4배, 한 번 더 누르면 원래대로. Ctrl+휠로 마우스 위치를 확대. 오른쪽 클릭 메뉴 → 돋보기에는 대비 강화, 검은 바탕에 노란 글자 같은 색(CtrlK로 전환)과 화면 정지(CtrlP)도 있습니다.

업데이트

새 버전이 있으면 창이 뜹니다. 지금 업데이트를 누르면 Zizai Cast가 닫히고 설치 후 자동으로 다시 열립니다. 지금은 아니면 나중에 알림. 오른쪽 클릭 메뉴 → 도움말 → 업데이트 확인으로도 확인할 수 있습니다.

기능 2원격 제어휴대폰으로 이 PC 조작

8원격 제어: 휴대폰으로 PC 조작

휴대폰 브라우저로 이 PC 화면을 보고, 소리를 듣고, 손가락으로 조작합니다. 휴대폰에 앱은 필요 없습니다(iPhone은 Safari, Android는 Chrome). 먼저 상황을 고르세요.

상황사용할 것PC 앞에 사람이 필요?
집에서, 휴대폰과 PC가 같은 Wi-FiQR 코드 스캔처음 “허용”만
내가 밖에서고정 주소 + 비밀번호(먼저 Tailscale 설정)설정할 때만
친구에게 잠시임시 계정(추천), 또는 임시 주소매번 “허용” 필요

원격 제어 켜기

메인 창 위쪽의 원격 제어 탭으로 바꾸고 맨 위 스위치를 켭니다. Zizai Cast를 시작할 때마다 원격 제어는 꺼져 있습니다(고급 설정에서 PC를 켜면 고정 주소 자동으로 켜기를 선택한 경우 제외). 연결 중에는 PC 화면 위쪽에 “원격 제어 중” 막대가 계속 표시되며 끊기나 CtrlD로 언제든 끝낼 수 있습니다.

고정 주소가 켜지면 맨 위 영역은 이 PC의 주소(밖에서도 접속 가능)가 됩니다. 작은 제목 아래에 큰 글씨로 주소, 옆에 QR 코드, 버튼은 주소 복사와 임시 계정 추가입니다. 임시 계정은 그 아래 별도 카드에, 집에서와 Tailscale은 한 줄씩 있습니다. 자주 쓰지 않는 것은 고급 설정에 있습니다: 고정 주소 비밀번호 변경…, 고정 주소(밖에서도 접속 가능)(선택을 해제하면 고정 주소가 꺼짐), PC를 켜면 고정 주소 자동으로 켜기, 그리고 소리(PC 소리를 휴대폰으로 보내기, 휴대폰에서 소리 재생 중 PC 음소거, 소리 가져올 장치).

상황 1: 집에서(같은 Wi-Fi)

하고 싶은 일소파에 앉아 서재의 PC를 휴대폰으로 조작합니다.

  1. PC: 원격 제어 탭 → 집에서(같은 Wi-Fi) 카드 → QR 코드 보기(스위치가 꺼져 있으면 자동으로 켜짐).
  2. 휴대폰을 같은 Wi-Fi에 연결하고 카메라로 QR 코드를 스캔해 주소를 누릅니다.
  3. PC에 “휴대폰이 이 PC를 조작하려고 합니다”: 내 휴대폰이면 허용. 이 휴대폰을 기억하고 다음부터 묻지 않기를 선택하면 다음부터 묻지 않습니다.
  4. 휴대폰에서 탭하면 소리가 나요나, 오른쪽 아래 소리 켜기라고 적힌 스피커를 누르면 PC 소리가 들립니다(iPhone은 이 탭이 필수).
성공하면 이렇게 보입니다휴대폰에 PC 화면이 나오고 PC 화면 위쪽에 “● 원격 제어 중”.
안 될 때
  • 휴대폰이 “PC에서 “허용”을 누르세요”에서 계속 돎: PC에서 허용을 누르세요(다른 창 뒤에 가려져 있을 수 있음).
  • 페이지가 안 열림: 휴대폰이 같은 Wi-Fi가 아니거나 공유기에 “AP 격리”가 켜져 있습니다. 연결이 안 돼요.

상황 2: 내가 밖에서(고정 주소)

하고 싶은 일모바일 데이터로 집 PC에 연결합니다. 주소는 바뀌지 않고, 내가 정한 비밀번호로 로그인합니다. PC에 Tailscale(무료)이 필요하고 휴대폰에는 아무것도 필요 없습니다.

할 일은 세 가지, 처음에는 약 15분① PC에 Tailscale 설치 후 로그인 → ② Tailscale에서 Funnel(외부 주소)과 HTTPS 허용 → ③ Zizai Cast에서 비밀번호를 정하고 고정 주소 켜기. 그다음은 휴대폰에서 주소만 열면 됩니다.

① PC에 Tailscale 설치, 가입, 로그인

  1. PC에서 tailscale.com/download/windows를 열고 다운로드해 설치(Windows 10 이상).
  2. 시계 옆에 Tailscale 아이콘이 나옵니다(안 보이면 ^). 오른쪽 클릭 → Log in으로 브라우저가 열립니다.
  3. Google, Microsoft, GitHub, Apple 계정으로 로그인(Tailscale 자체 비밀번호는 없고 이메일만으로는 가입할 수 없습니다). 처음에 용도를 물으면 Personal use.
  4. 아이콘을 다시 오른쪽 클릭해 내 계정과 Connected가 보이면 끝.
성공하면 이렇게 보입니다Zizai Cast의 밖에서: Tailscale 카드에 “이 PC에는 아직 Tailscale이 없습니다”가 더 이상 나오지 않습니다(계속 나오면 원격 제어를 껐다 켜기).

② Funnel과 HTTPS 허용(새 계정은 필수)

새 Tailscale 계정은 처음에 외부 주소(Funnel)를 허용하지 않고 HTTPS 인증서도 아직 없습니다. 한 번만 하면 되고, 가장 쉬운 방법은 Zizai Cast의 안내를 따르는 것입니다.

  1. 먼저 아래 ③을 하고 켜기를 누릅니다.
  2. 영역에 “Tailscale 계정에서 아직 Funnel이 켜져 있지 않습니다(처음 한 번만 필요)”(또는 HTTPS 인증서)가 나오면 설정 페이지 열기. 브라우저에 Tailscale 페이지가 열리면 같은 계정으로 로그인해 켜기(Enable)를 누릅니다.
  3. Zizai Cast로 돌아와 켰어요, 다시 시도를 누릅니다.

명령으로 하는 방법(결과는 같음):

  1. 시작을 오른쪽 클릭 → 터미널(또는 “명령 프롬프트” 검색).
  2. 다음 한 줄을 붙여 넣고 Enter(숫자는 그대로 두세요. 나중에 Zizai Cast가 올바른 설정으로 바꿉니다): 
    tailscale funnel --bg --https=8443 http://127.0.0.2:8091
  3. 처음에는 Funnel을 허용하라는 링크가 출력됩니다. 선택해 복사하고 브라우저에서 열어 같은 계정으로 로그인한 뒤 허용(Enable)합니다. HTTPS 인증서와 Funnel이 자동으로 켜집니다.
  4. 터미널로 돌아가 아직 기다리고 있으면 같은 줄을 한 번 더 실행. 오류가 없으면 터미널을 닫아도 됩니다.
PC 이름이 공개됩니다HTTPS를 켤 때 Tailscale은 “기기 이름과 tailnet 이름이 공개 인증서 기록에 남는다”고 알려 줍니다. PC 이름이 실명이면 먼저 Windows 설정 → 시스템 → 정보 → “이 PC 이름 바꾸기”에서 바꾸세요.

③ Zizai Cast에서 비밀번호를 정하고 고정 주소 켜기

  1. 원격 제어 탭 맨 위 원격 제어 허용 영역에서 비밀번호 설정(고정 주소와 임시 계정). 두 번 입력, 8자 이상(길수록 좋고 다른 곳에 쓰지 않는 것). 저장하고 켜기.
  2. 처음에는 1~2분 기다리기: 영역에 “주소를 준비하고 있습니다(약 1~2분…)”가 나오는 동안 Tailscale이 HTTPS 인증서를 받고 있어 휴대폰에서 열리지 않습니다. Zizai Cast가 직접 확인하고, 연결되면 “고정 주소를 켰습니다”를 보여 줍니다.
  3. 영역이 이 PC의 주소(밖에서도 접속 가능)로 바뀌고 https://PC이름.….ts.net:8443/가 큰 글씨로 QR 코드와 함께 나옵니다. 휴대폰으로 스캔하거나 주소 복사로 나에게 보냅니다.
  4. 휴대폰에서 주소를 열면 비밀번호 칸만 있습니다. 내 비밀번호를 입력. 한 번 로그인하면 이 휴대폰은 30일 동안 묻지 않습니다. 홈 화면에 추가하면 한 번에 열 수 있습니다.
  5. PC를 켜자마자 밖에서 쓰려면 고급 설정 → PC를 켜면 고정 주소 자동으로 켜기를 선택.
성공하면 이렇게 보입니다비밀번호를 넣으면 휴대폰에 PC 화면이 나옵니다. 밖에서는 PC 앞에 사람이 없어도 됩니다.
안 될 때
  • 영역에 “Funnel(또는 HTTPS 인증서)이 아직 켜져 있지 않습니다”: ②처럼 설정 페이지 열기로 켠 뒤 켰어요, 다시 시도.
  • “Tailscale에 로그인되어 있지 않습니다”나 “응답이 없습니다”: PC에서 Tailscale을 열고 로그인한 뒤 다시 시도.
  • 계속 “주소를 준비하고 있습니다”: 조금 더 기다리세요. 5분이 지나도 연결되지 않으면 안내가 바뀝니다. 다시 시도나 우선 임시 주소 사용(매번 바뀜).
  • “고정 주소를 켰습니다”가 나왔는데 휴대폰에서 안 열림: 여기.
  • 비밀번호를 5번 틀리면 15분 잠금. 잊었다면 PC의 고급 설정 → 고정 주소 비밀번호 변경…으로만 다시 정할 수 있습니다.

Tailscale 단계 출처(2026년 10월 확인): tailscale.com/kb/1223(Funnel: MagicDNS, HTTPS, funnel 속성 필요, tailscale funnel 실행 시 활성화 안내, 포트는 443·8443·10000만), /kb/1311(명령, --bg, --https, off), /docs/how-to/set-up-https-certificates(DNS 페이지의 Enable HTTPS, Let's Encrypt 인증서, 이름 공개).

다른 방법: 휴대폰에도 Tailscale

휴대폰에도 Tailscale 앱을 설치하고 같은 계정으로 로그인하면 집처럼 연결됩니다. 밖에서: Tailscale 카드 → QR 코드 보기를 집에서 한 번 스캔해 홈 화면에 추가하고, 밖에서는 휴대폰의 Tailscale을 켜 두세요. 비밀번호도 Funnel도 필요 없습니다.

페이지를 홈 화면에 추가

  • iPhone: Safari로 페이지 열기 → 공유 → 홈 화면에 추가.
  • Android: Chrome으로 페이지 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가.

상황 3: 친구에게 빌려주기

하고 싶은 일멀리 있는 친구가 잠시 내 PC를 보거나 조작하게 하고(문제를 도와 달라고), 끝나면 못 쓰게 합니다. 내 고정 주소 비밀번호는 남에게 알려 주지 마세요. 두 방법 모두 친구가 로그인한 뒤 처음 연결할 때 PC 앞에서 누군가 “허용”을 눌러야 합니다(기억할 수 없음). 한 번 허용하면 같은 휴대폰이 같은 계정(또는 같은 임시 주소)으로 화질 변경, 화면 전환, 끊긴 뒤 다시 연결, 페이지 새로 고침을 해도 다시 묻지 않습니다. 거부나 연결 끊기를 한 뒤, 또는 계정이 만료되거나 삭제되면 다시 허용해야 합니다.

방법 A: 임시 계정(추천, 고정 주소를 먼저 켜 두기)

  1. PC: 원격 제어 탭 맨 위의 이 PC의 주소(밖에서도 접속 가능) 영역 → 임시 계정 추가.
  2. 계정 이름은 자동으로 들어가 있습니다(예: guest-4821, 바꿀 수 있음). 유효 기간: 한 번만/1시간/24시간/7일, 권한: 조작 가능/보기만, 파일 전송 가능(휴대폰과 PC 양방향)은 처음부터 켜져 있습니다. 파일을 주고받게 하고 싶지 않으면 끄세요(보기만에서는 회색이 되며 파일 전송을 할 수 없습니다). 만들기를 누릅니다.
  3. 모두 복사해서 친구에게 붙여 넣습니다. 주소에 계정이 들어 있습니다(#u=guest-4821). 비밀번호는 지금만 표시됩니다(잊으면 비밀번호 재설정).
  4. 친구가 주소를 열면 계정은 이미 입력되어 있어 비밀번호만 넣으면 됩니다. PC에 “휴대폰이 이 PC를 조작하려고 합니다”가 나오면 친구가 맞는지 확인하고 허용. 계정이 유효한 동안에는 같은 휴대폰이면 다시 묻지 않습니다.
  5. 기간이 끝나거나 “한 번만”을 다 쓰면 자동으로 삭제됩니다. 아래 임시 계정 카드의 삭제로도 지울 수 있습니다(연결 중이면 바로 끊김). 최대 10개.

방법 B: 임시 주소(고정 주소 없이)

  1. PC: 고정 주소가 없으면 원격 제어 허용 영역의 임시 주소 만들기, 고정 주소가 있으면 고급 설정 → 임시 주소(휴대폰에 앱 없이, 모바일 데이터로도 연결). 10~20초 뒤 QR 코드와 6자리 통행 코드가 나옵니다(작은 창의 임시 주소 탭에도. 작은 창의 탭은 같은 Wi-Fi, 고정 주소, Tailscale, 임시 주소 순서로 메인 화면과 같습니다).
  2. 주소 복사로 친구에게 주소를 보내고 통행 코드는 따로 알려 줍니다. 주소는 한 번만, 10분 안에 쓸 수 있습니다.
  3. 친구가 열고 통행 코드를 넣으면 PC에 “휴대폰이 이 PC를 조작하려고 합니다”가 나옵니다. 내가 PC 앞에서 “허용”을 누릅니다.
  4. 끝나면 임시 주소 중지, 또는 원격 제어를 끕니다.
성공하면 이렇게 보입니다친구 휴대폰에 내 PC가 보이고 화면 위쪽에 “● 원격 제어 중”. 언제든 끊기나 CtrlD로 끝낼 수 있습니다.
안 될 때
  • 친구에게 “이 주소는 더 이상 유효하지 않습니다”: 주소는 한 번, 10분만. 중지하고 새로 받으세요.
  • 친구가 “PC에서 “허용”을 누르세요”에서 계속 기다림: 내가 PC에서 허용을 눌러야 합니다(임시 주소도 임시 계정도 새로 로그인할 때마다 한 번).
  • 친구의 파일 버튼이 회색: 누르면 이유가 나옵니다. 임시 계정을 파일 전송 가능을 끄고 만들었거나(켜고 다시 만드세요) 보기만 상태입니다.
  • “임시 주소에 아직 밖에서 연결할 수 없습니다”: 중지하고 새로 받으세요.
끝난 뒤에는친구가 다 쓰면 끊기를 누르고 임시 주소를 중지하세요. 상대는 화면 전체를 볼 수 있으니 개인적인 창은 먼저 닫으세요. 보기만 하게 하려면 PC 화면 위쪽 막대에서 보기 전용을 켭니다.

휴대폰에서 조작: 직접 터치와 트랙패드

휴대폰 페이지 오른쪽 아래에 아이콘 6개가 있고 아래에 글자가 나옵니다: 소리 켜기(켜면 소리), 확대, 파일(파일 전송을 할 수 없으면 회색, 누르면 이유), 키보드, 통계(지연, 초당 프레임), 설정. 처음 연결하면 지금 조작 방식을 알려 주는 카드가 나오고, 한 번에 바꿀 수 있습니다. 설정 → 조작 방식에서 고릅니다(아래 작은 설명이 차이입니다).

조작 방식사용법이런 분께
직접 터치(기본)손가락이 닿은 곳을 클릭. 0.5초 누르기 = 오른쪽 클릭, 누른 채 움직이기 = 드래그큰 버튼, 메뉴, 처음 쓰는 분
트랙패드노트북 터치패드처럼 손가락을 밀어 포인터 이동. 탭 = 왼쪽 클릭, 두 손가락 탭 = 오른쪽 클릭, 두 손가락 밀기 = 스크롤작은 것 누르기, 글자 선택

트랙패드에서는 PC 포인터 위치에 큰 화살표(분홍색 원)가 보이고, 탭하면 그곳을 클릭합니다. 화살표에서 먼 곳을 계속 누르면 직접 터치로 바꿀지 묻습니다. 두 손가락으로 벌리면 확대, 세 손가락 탭으로 키보드 열기/닫기. 키보드 패널에는 Ctrl, Alt, Win, 방향키, 복사, 붙여넣기, 클립보드가 있습니다.

다른 컴퓨터의 브라우저에서 조작하기

다른 컴퓨터의 브라우저(Chrome, Edge 등)에서 같은 주소를 열면 그 컴퓨터의 마우스와 키보드로 조작할 수 있습니다. 왼쪽·오른쪽·가운데 버튼, 뒤로/앞으로 버튼, 휠, 드래그가 그대로 전달되고, 가리킨 곳을 클릭합니다. 글자는 그 컴퓨터의 입력기(한국어·중국어·일본어도)로 입력하며, 단축키(Ctrl+C, Ctrl+V, F5 등)는 브라우저가 아니라 원격 PC로 갑니다.

  1. 마우스를 화면 맨 위로 가져가면 바가 나옵니다: 전체 화면, 원래 크기/창에 맞추기, 화면마다 버튼(두 개 이상일 때), 게임 모드, Alt+Tab, Win, Ctrl+Alt+Del, Ctrl+W, 작업 관리자, 클립보드, 소리, 파일, 통계, 설정.
  2. 전체 화면에서는 Alt+Tab, Win 같은 키도 원격 PC로 갑니다. Esc를 길게 누르면 전체 화면이 끝납니다. 브라우저가 이런 키를 페이지에 넘기지 않으면 어떤 키가 가지 않는지 알려 주는 카드가 나옵니다. 바의 버튼을 쓰거나 다시 시도를 누르세요.
  3. 이 컴퓨터에서 Ctrl+V를 누르면 이 컴퓨터 클립보드의 글자가 원격 PC에 붙여 넣어집니다. 원격 PC에서 복사한 글자는 이 컴퓨터 클립보드로 옵니다.
  4. 게임이나 3D 프로그램에는 게임 모드: 마우스가 화면 안에 고정됩니다. Esc 또는 Ctrl+Alt+Shift+Q로 나가기, Ctrl+Alt+Shift+M 다음 화면, Ctrl+Alt+Shift+S 통계 켜기/끄기(이 세 가지는 원격 PC로 보내지 않음).
안 될 때
  • 클릭해도 반응이 없고 “이 창은 관리자 권한으로 실행 중”이라고 나옴: 그 프로그램이 관리자 권한으로 실행되어 원격으로 클릭할 수 없습니다. 일반 권한으로 다시 열거나 Zizai Cast를 관리자 권한으로 실행하세요.
  • Ctrl+Alt+Del이 가지 않음: Windows 보안 키라서 어떤 프로그램도 보낼 수 없습니다. 작업 관리자는 바의 작업 관리자로.
  • 바의 파일이 회색: 마우스를 올리면 이유가 나옵니다(보기만, 또는 파일 전송이 없는 임시 계정).

안전 수칙

  • 고정 주소는 공개되어 있고 막아 주는 것은 비밀번호뿐입니다. 길고 다른 곳에 쓰지 않는 것을 쓰세요.
  • 연결 중에는 PC 화면 위쪽에 “● 원격 제어 중”이 계속 보이고, CtrlD는 어떤 프로그램에서든 연결을 끊습니다.
  • 휴대폰을 30분 동안 만지지 않으면 자동으로 끊깁니다(고급 설정에서 변경).
  • 고급 설정 → 원격 연결이 끊기면 PC 잠그기: 연결이 끝나면 PC를 잠급니다. 기본값은 꺼짐(밖에서도 집에서도), 필요하면 직접 켜세요.
  • 더 이상 밖에서 쓸 일이 없으면 고급 설정에서 PC를 켜면 고정 주소 자동으로 켜기와 고정 주소(밖에서도 접속 가능)를 해제(해제하면 고정 주소가 꺼짐).

할 수 없는 것

  • 관리자 권한으로 실행한 창, UAC 확인 창, 잠금 화면은 휴대폰으로 조작할 수 없습니다(Windows 제한). 그런 창을 클릭하면 휴대폰 페이지가 이유를 알려 줍니다.
  • 꺼져 있거나 절전 중이거나 로그인 화면에 있는 PC에는 연결할 수 없습니다. 한 번에 휴대폰 한 대만.
기타소리, 문제 해결

9소리 크기 조절

하고 싶은 일소리가 작거나 크거나 안 납니다. 먼저 어느 쪽인지 확인하세요.

휴대폰을 PC에 미러링할 때(소리는 PC에서)

  1. iPhone: iPhone 음량 버튼만 누르면 PC 음량도 바뀌고 Zizai Cast가 기억합니다.
  2. PC: 오른쪽 클릭 메뉴 → 음량(예: “음량: 50%”) 또는 화면 오른쪽 아래 스피커.
  3. 그래도 소리가 없으면: 스피커를 오른쪽 클릭 → “볼륨 믹서”에서 Zizai Cast가 음소거되지 않았는지 확인.
성공하면 이렇게 보입니다음량을 바꾸면 화면에 지금 음량이 잠깐 표시됩니다.

원격 제어(PC 소리를 휴대폰에서)

  1. 휴대폰 페이지는 처음에 소리가 꺼져 있습니다(iPhone 규칙). 탭하면 소리가 나요나 오른쪽 아래 소리 켜기라고 적힌 스피커를 누르세요.
  2. PC가 음량을 자동으로 맞추므로 휴대폰 음량은 기본 100%로 보통 충분합니다. 그래도 작으면 오른쪽 아래 설정 → 휴대폰 음량을 오른쪽으로(0~400%). 100%는 PC에서 보낸 원래 크기입니다. 100%를 넘으면 “음량 강화”: 오른쪽일수록 크게, 작은 소리일수록 더 키우며 찢어지지 않습니다.
  3. 휴대폰 자체 음량도 올리고, iPhone의 무음 스위치는 끄세요.
  4. PC: 원격 제어 탭 → 고급 설정 → 소리의 PC 소리를 휴대폰으로 보내기를 선택. PC에서는 소리를 내지 않으려면 같은 곳의 휴대폰에서 소리 재생 중 PC 음소거를 선택하거나, 휴대폰 페이지 설정에서 PC 스피커 음소거를 켜세요(같은 설정이며 PC에 저장됩니다. 임시 계정과 “보기 전용”에서는 바꿀 수 없음).
안 될 때
  • “PC에서 지금 재생 중인 소리가 없습니다”: PC에서 정말 소리가 나지 않고 있습니다.
  • PC의 Windows가 음소거: 음소거를 해제하세요. PC를 조용히 하려면 “휴대폰에서 소리 재생 중 PC 음소거”(휴대폰 페이지에서는 “PC 스피커 음소거”).
  • 더 보기: 원격 제어에서 소리가 안 나요, 미러링에서 소리가 안 나요.

10문제 해결

질문을 누르면 답이 열립니다.

휴대폰 미러링

휴대폰 목록에 “Zizai Cast”가 없어요
  • Zizai Cast가 실행 중인지(오른쪽 아래 아이콘).
  • 휴대폰과 PC가 같은 Wi-Fi인지, 게스트 네트워크나 모바일 데이터가 아닌지.
  • 양쪽 VPN 끄기, 방화벽 허용 확인(방화벽).
  • 학교, 회사, 호텔 네트워크는 자주 막습니다. 집 네트워크나 PC 핫스폿으로.
  • AirServer, LonelyScreen 같은 다른 수신 앱을 닫기.
  • 휴대폰 Wi-Fi를 껐다 켜거나 Zizai Cast를 다시 열기.
미러링에서 화면은 나오는데 소리가 없어요
  • iPhone 음량 버튼으로 올리고 무음 스위치를 끄기.
  • PC 스피커와 “볼륨 믹서”에서 Zizai Cast가 음소거가 아닌지.
  • 이어폰이나 스피커를 바꿨으면 한 번 다시 연결.
  • 저작권 보호 때문에 미러링 중 소리나 화면을 막는 동영상 앱이 있습니다(Zizai Cast 문제가 아님).
화면이 늦거나 끊겨요
  • 양쪽 모두 5 GHz Wi-Fi, 공유기 가까이. PC는 랜선이 유리.
  • 오른쪽 클릭 메뉴 → 설정 → 화질 → 표준(부드러움).
  • 큰 다운로드를 멈추기.
화면이 흐려요
  • 오른쪽 클릭 메뉴 → 설정 → 화질을 “높음”이나 “최고”로. 회색이면 Microsoft Store에서 “HEVC 비디오 확장”을 설치.
  • 바꾼 뒤 안내 옆의 지금 다시 연결해 적용.
도중에 다른 휴대폰으로 바뀌었어요

오른쪽 클릭 메뉴 → 설정 → 두 번째 휴대폰이 연결되면 → 지금 휴대폰 유지. 새 휴대폰은 PIN으로 연결을 켜는 방법도 있습니다.

방화벽: 처음에 “취소”를 눌렀어요
  1. 시작 → “Windows 방화벽을 통해 앱 허용” 검색.
  2. 설정 변경을 누르고 “自在投影”(Zizai Cast)의 개인을 선택.
  3. 목록에 없으면 다른 앱 허용…으로 설치 폴더의 “自在投影.exe”를 선택.
VPN을 켜면 연결이 안 돼요

미러링 중에는 PC와 휴대폰의 VPN을 끊으세요. “LAN 접근 허용” 같은 설정이 있는 VPN이면 그것을 켜도 됩니다.

Android 화면 전송(Miracast)이 연결되지 않아요
  • PC의 Wi-Fi는 켜고 모바일 핫스폿은 끄기.
  • 지원 확인: 시작을 오른쪽 클릭 → 터미널에서 netsh wlan show drivers. “Wireless Display Supported(무선 디스플레이 지원)”가 둘 다 Yes여야 합니다.
  • No이거나 Google Pixel: Android 조작을 쓰세요.
Android 조작이 끊기거나 다음에 자동 연결이 안 돼요
  • Android는 휴대폰을 다시 시작하면 무선 디버깅을 끕니다(Wi-Fi 변경 후에도 자주 꺼짐). Zizai Cast가 한 번 “이전에 페어링한 휴대폰을 찾지 못했습니다…”라고 알려 줍니다. 개발자 옵션에서 다시 켜면 되고 다시 페어링할 필요는 없습니다.
  • 절전 기능이 화면이 꺼지면 Wi-Fi를 끊을 수 있습니다. 연결된 동안 절전 모드 해제를 켜세요.
  • CtrlD로 끊은 휴대폰은 저절로 돌아오지 않습니다. “Android 연결(QR 스캔)”이나 Zizai Cast를 다시 열기.
  • 그래도 안 되면 휴대폰의 “무선 디버깅 → 페어링된 기기”에서 이 PC를 지우고 다시 페어링.
“연결 끊기”가 어디 있나요?

화면 위쪽으로 마우스를 가져가면 나오는 도구 모음 오른쪽 끝의 빨간 버튼. CtrlD, 또는 오른쪽 아래 아이콘을 오른쪽 클릭 → 연결 끊기. Android 화면에서는 오른쪽 클릭 = “뒤로”라서 메뉴는 Shift+오른쪽 클릭.

번역이 반응이 없거나 일본어·한국어가 번역되지 않아요
  • 처음에는 모델 다운로드가 필요합니다. 물으면 다운로드(약 50 MB).
  • 일본어·한국어를 못 읽음: 안내의 언어 설정 열기, 또는 Windows 설정 → 시간 및 언어 → 언어 및 지역 → 언어 추가 → 일본어(한국어) → “광학 문자 인식”만 선택 → 설치.

원격 제어

고정 주소가 켜지지 않아요(새 Tailscale 계정)
  • 새 계정은 먼저 Funnel과 HTTPS를 허용해야 합니다: 영역의 설정 페이지 열기, 또는 ② Funnel과 HTTPS 허용을 한 번 하세요.
  • 또는 Tailscale 관리 페이지(login.tailscale.com/admin)의 DNS 페이지에서 MagicDNS를 켜고 HTTPS Certificates의 Enable HTTPS, 이어서 Access controls에 funnel 권한 추가. 명령이 더 쉽습니다.
  • PC의 Tailscale이 실행 중이고 로그인되어 있어야 합니다.
고정 주소를 막 켰는데 휴대폰에 ERR_CONNECTION_CLOSED가 나와요

처음에는 Tailscale이 HTTPS 인증서를 받는 동안 열리지 않습니다. Zizai Cast가 직접 확인합니다. 영역에 “주소를 준비하고 있습니다(약 1~2분)”가 나오는 동안은 기다리세요. 연결되면 “고정 주소를 켰습니다”가 나옵니다. 그렇게 나왔는데도 안 열리면 휴대폰 쪽 DNS가 아직 새 이름을 모를 수 있습니다(Tailscale은 최대 10분이라고 합니다). 조금 뒤 새로 고침. 그래도 안 되면 PC의 고급 설정에서 고정 주소(밖에서도 접속 가능)를 해제했다가 다시 선택.

휴대폰에서 PC에 연결이 안 돼요
  • 집에서 QR이 안 열림: 휴대폰이 같은 Wi-Fi가 아님(게스트, 모바일 데이터 불가), 또는 공유기 AP 격리.
  • 고정 주소가 안 열림: PC가 켜져 있고 로그인되어 있으며 Tailscale이 실행 중이어야 합니다. 처음이면 위 질문 참고.
  • 페이지는 열리는데 “화면 연결이 차단되었습니다”: Windows 방화벽(원격 제어를 처음 켤 때 “액세스 허용”), AP 격리, 다른 VPN.
  • “이 주소는 더 이상 유효하지 않습니다”: PC의 QR 코드를 다시 스캔(홈 화면 아이콘도 다시 추가).
원격 제어에서 소리가 안 나거나 작아요
  • 탭하면 소리가 나요(또는 소리 켜기라고 적힌 스피커)를 누르세요. 그래도 작으면 휴대폰 페이지 설정 → 휴대폰 음량을 오른쪽으로(기본 100%, 100%를 넘으면 음량 강화, 최대 400%).
  • iPhone 무음 스위치와 휴대폰 음량.
  • PC에서 Windows를 음소거하지 않기. 고급 설정 → 소리 → PC 소리를 휴대폰으로 보내기 선택.
고정 주소 비밀번호를 잊었어요

PC에서만 다시 정할 수 있습니다: 원격 제어 탭 → 고급 설정 → 고정 주소 비밀번호 변경…. 휴대폰은 새 비밀번호로 다시 로그인합니다.

PC가 잠겼어요

켜 두었다면(기본은 꺼짐) 원격 연결이 끝날 때 PC가 잠깁니다. Windows 비밀번호나 PIN으로 풀어 주세요. 원하지 않으면 고급 설정 → 원격 연결이 끊기면 PC 잠그기를 해제.

창을 닫아도 실행 중인가요?

네, 오른쪽 아래에서 백그라운드로 대기합니다. 완전히 끝내려면 아이콘을 오른쪽 클릭 → 종료.
