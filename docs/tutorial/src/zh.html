0開始之前

手機是透過網路找到電腦的。大部分「找不到自在投影」都是下面這幾件事。

{{fig:net}}
  1. 手機和電腦連同一個 Wi-Fi。電腦用網路線接在同一台分享器上也可以。手機的「行動數據」「個人熱點」「訪客 Wi-Fi」都不算。
  2. 第一次開啟時允許防火牆。Windows 跳出「Windows 安全性警示」時，勾私人網路，按允許存取。按到取消的話看這裡。
  3. 先關掉 VPN。電腦或手機開著 VPN，手機常常看不到電腦。

打開自在投影會看到什麼

視窗上方有兩個分頁：手機投影和遠端控制。「手機投影」分頁寫著請選你的手機，下面三張卡片，點你的手機那一張的按鈕就好。

{{img:idle|等待畫面：三張卡片，各有一個按鈕|420}}

關掉視窗不會結束程式：它會問你要結束還是背景待命。選背景待命，它會縮到右下角時鐘旁邊的小圖示，手機一連上視窗就跳出來。

1iPhone 投影

你要做什麼把 iPhone / iPad 的畫面和聲音放到電腦上。不用裝 App。

{{fig:iphone}}
  1. 電腦上開著自在投影（視窗或右下角有它的圖示）。
  2. iPhone 打開控制中心：有 Face ID 的從右上角往下滑；有圓形主畫面按鈕的從底部往上滑。
  3. 點螢幕鏡像（兩個重疊方框的圖示）。
  4. 在清單裡點自在投影。
看到這個就成功幾秒內電腦出現手機畫面，下方提示「已連線：手機名稱……滑鼠移到上方有工具列」。第一次連上時工具列會說明「常用功能都在這條工具列：截圖、錄影、翻譯、放大。滑鼠移到畫面上方就會出現，停在上面就不會收起。」工具列收起時，畫面最上面有一條粉紅色細線，告訴你它在那裡。
{{img:toolbar|滑鼠移到畫面上方就出現工具列（停在上面不會收起）：截圖、錄影、畫筆、傳到手機、音量、放大、翻譯……最右邊紅色是中斷連線|640}}
不成功怎麼辦
  • 清單裡沒有「自在投影」：看找不到自在投影。
  • 有畫面沒聲音：按 iPhone 側邊的音量鍵調大，看聲音大小。
  • 要輸入 4 位數 PIN：電腦畫面上有數字，照著在 iPhone 輸入（設定裡開了「連線要輸入 PIN」才會問）。

結束投影

iPhone 控制中心 → 螢幕鏡像 → 停止鏡像輸出；或在電腦按 CtrlD、工具列最右邊的紅色中斷連線。iPhone 鎖螢幕時畫面會暫停，解鎖後自動繼續。

中斷連線的四個地方（iPhone、Android 都一樣）：工具列最右邊紅色按鈕、CtrlD、右鍵選單最上面的中斷連線、右下角圖示按右鍵 → 中斷連線（手機名稱）。正在錄影會先存好。

2Android 投放（Miracast）

你要做什麼把 Android 手機畫面放到電腦上，只看、不操作。不用設定，但電腦要有支援「無線顯示器」的 Wi-Fi 網卡（大部分筆電可以）。

{{fig:cast}}
  1. 電腦開著自在投影，電腦的 Wi-Fi 要開著（就算用網路線上網也要開）。
  2. 手機從螢幕頂端往下滑兩次，找到投放的圖塊：Samsung 叫Smart View，小米叫投放，OPPO 叫螢幕投放，vivo 叫投屏。
  3. 在清單裡點自在投影，第一次可能要等 10～20 秒。
看到這個就成功電腦出現手機畫面，下方提示「已連線」。要結束：手機再點一次同一個圖塊，或電腦按 CtrlD。
不成功怎麼辦
  • 等待畫面的「Android 只要看」卡片是灰色、寫「了解原因」：這台電腦收不到 Miracast，點「了解原因」，或改用下一段的Android 操控。
  • Google Pixel 沒有 Miracast（它的「投放」只給 Chromecast 用），請用Android 操控。
  • 一直停在「正在連線」：手機取消，等 10 秒再試；或看Miracast 連不上。
品牌快速設定圖塊或在「設定」裡
SamsungSmart View設定 → 已連接的裝置 → Smart View
Xiaomi / Redmi / POCO投放、無線投放設定 → 連線與共享 → 投放
OPPO / realme / OnePlus螢幕投放設定 → 連線與共享 → 螢幕投放
vivo / iQOO投屏設定 → 其他網路與連線 → 投屏
ASUS / Sony無線投影／螢幕鏡像設定 → 已連線的裝置 → 連線偏好設定

3Android 操控（QR 配對、USB）

你要做什麼在電腦上看 Android 手機，還能用滑鼠點、用鍵盤打字。第一次要設定約 5 分鐘，之後自動連上。需要 Android 11 以上。

第一步：打開「開發人員選項」（只做一次）

{{fig:devopt}}
  1. 手機：設定 → 關於手機（Samsung 再點軟體資訊）。
  2. 找到版本號碼，連點 7 下，可能要輸入手機解鎖密碼。
  3. 出現「你現在已成為開發人員」就好了。設定裡會多一個開發人員選項（通常在「系統」裡或最下面）。

電腦上的配對視窗也有這些步驟：按① 還沒開過「開發人員選項」？看步驟。「版本號碼」在哪裡：Samsung 是關於手機 → 軟體資訊；小米／Redmi 是我的裝置 → 全部參數與資訊 → OS 版本（或 MIUI 版本），連點這一項 7 下；Pixel 是關於手機的最下面。之後的開發人員選項：Samsung 在設定最下面，小米在「更多設定」，Pixel 在「系統」。

{{img:pair-steps|配對視窗裡的「開發人員選項」步驟|340}}

第二步：掃 QR 碼配對（只做一次）

{{fig:pair}}
  1. 手機：開發人員選項 → 打開無線偵錯，問你要不要允許時按允許。
  2. 電腦：等待畫面「Android 用電腦操控」卡片按顯示 QR 碼（或右鍵選單 → 連接手機 → 連接 Android（掃 QR））。
  3. 手機：點「無線偵錯」這幾個字進去 → 使用 QR 圖碼配對裝置，對準電腦上的 QR 碼。
{{img:pair|電腦上的配對視窗（示範用的假 QR 碼）|380}}
看到這個就成功配對視窗自己關掉，電腦出現手機畫面，提示「已連線：手機名稱。滑鼠移到上方有工具列；右鍵＝返回」。之後只要手機的無線偵錯開著、在同一個 Wi-Fi，就會自動連上。
不成功怎麼辦
  • 一直「等待手機掃描…」：手機和電腦不在同一個 Wi-Fi（訪客網路不行）。也可以按用配對碼，在手機點「使用配對碼配對裝置」，把手機上的 IP 位址:連接埠和 6 位數字輸入電腦。
  • 配對失敗：視窗會換一個新的 QR 碼，手機重新點「使用 QR 圖碼配對裝置」再掃一次。
  • 一陣子沒人掃：QR 碼變暗、寫著已逾時，下面寫「等太久，已停止。確認在同一個 Wi-Fi、手機已開「無線偵錯」……」。按重新產生 QR拿一個新的 QR 碼，再掃一次。
  • 重開機後沒有自動連上：Android 重開機會把無線偵錯關掉，自在投影會提示一次「找不到之前配對過的手機。如果手機剛重開機，要到「開發人員選項」重新開啟「無線偵錯」，再試一次」。回開發人員選項把無線偵錯再打開就好，不用重新配對。

沒有 Wi-Fi？用 USB 線

  1. 手機：開發人員選項 → 打開USB 偵錯。
  2. 用傳輸線接上電腦，手機問「要允許 USB 偵錯嗎？」時勾一律允許這部電腦，按允許。
  3. 電腦：右鍵選單 → 連接手機 → 用 USB 線連線。
看到這個就成功提示「正在用 USB 線連線…」之後出現手機畫面。
不成功怎麼辦
  • 「找不到 USB 線上的 Android 手機」：換一條能傳資料的線（有些線只能充電），確認 USB 偵錯開著，拔掉重插。
  • 手機沒問你要不要允許：手機下拉通知，把 USB 模式改成「檔案傳輸」再試。

4錄影和截圖

你要做什麼把手機畫面拍一張圖，或錄成影片（有聲音的 MP4）。手機畫面出現以後才能用。

  1. 滑鼠移到手機畫面上方，出現工具列。
  2. 截圖：點截圖（或按 CtrlS）。
  3. 錄影：點錄影（或 CtrlR），左上角出現紅點和秒數；要停止再點一次。
  4. 找檔案：右鍵選單 → 開啟截圖資料夾／開啟錄影資料夾。
{{img:snapshot|截圖：下方提示「截圖已存到「圖片\截圖」資料夾」，後面有「查看」|260}} {{img:recording|錄影中：左上角紅點和秒數|260}}
看到這個就成功截圖後提示「截圖已存到「圖片\截圖」資料夾」，點後面的查看就打開這張圖（提示停 8 秒，滑鼠停在上面不會消失）；錄影停止後提示「錄影已儲存：檔名」。下方會出現一排小按鈕開啟資料夾·傳到手機。
不成功怎麼辦
  • 按鈕是灰色、寫「手機連上後可用」：先讓手機畫面出現。
  • 不能錄影：硬碟剩不到 300 MB 時不能錄，清一點空間。
  • 錄到一半手機斷線：已經錄的部分會自動存好。

5畫筆

你要做什麼在投影的畫面上畫線、畫箭頭、畫螢光筆，講解給旁邊的人看。筆跡只在電腦上，不會畫到手機裡。

  1. 滑鼠移到畫面上方，點工具列的畫筆（或 CtrlE）。
  2. 按住滑鼠左鍵拖曳就能畫。工具列會換成工具（筆 → 螢光筆 → 箭頭）、顏色、粗細、復原、清除。
  3. 畫完按 Esc（或再按一次 CtrlE）結束畫筆，筆跡會留著；CtrlShiftE 全部清除。
{{img:ink|畫筆模式：紅色的筆和黃色的筆，下方提示「筆 · 黃 · 中」|280}}
看到這個就成功提示「畫筆模式：在畫面上拖曳就能畫（Esc 結束）」，畫面四周有一圈粉紅色框，左下角有「畫筆模式 · 按 Esc 或 Ctrl+E 結束」。截圖和錄影預設會包含筆跡（右鍵選單 → 畫筆可以關掉）。
不成功怎麼辦
  • Android 操控時一畫就點到手機：畫筆模式下滑鼠暫停操控手機；要點手機先按 Esc 或 CtrlE。
  • 畫錯了：CtrlZ 復原上一筆。

6拖檔和傳到手機

你要做什麼把電腦上的照片、影片、文件，或剛剛的截圖、錄影，送到手機上。

方法一：把檔案拖進自在投影的視窗

  1. 在檔案總管選好檔案，拖到自在投影的視窗上（不要放開），視窗會說放開會發生什麼。
  2. 放開。
{{img:drop|拖到 Android 手機的畫面上：「放開以安裝 App／傳到手機」|280}}
看到這個就成功Android 操控中：直接傳進手機（.apk 會直接安裝），提示「已傳到手機：檔名」或「已安裝：檔名」。iPhone、Miracast 或還沒連手機：電腦出現 QR 碼，照方法二的第 3 步用手機掃。

方法二：傳到手機（QR 碼）

  1. 右鍵選單 → 傳到手機 → 把最後一張截圖傳到手機（或傳到手機…自己挑檔案）。工具列也有這顆按鈕。
  2. 有好幾個新檔案時會先讓你勾要傳哪些，按傳送 N 個。
  3. 手機連同一個 Wi-Fi，用相機掃電腦上的 QR 碼，打開網頁。照片：長按 →「加入照片」（iPhone）或「下載圖片」（Android）；影片：點「下載影片」。
{{img:picker|有好幾個新檔案時：勾選要傳的|360}} {{img:share|手機掃這個 QR 碼（示範用，連結 10 分鐘後失效）|300}}
看到這個就成功手機打開一個網頁，列出檔案，可以存到相簿。
不成功怎麼辦
  • 手機打不開網頁：手機不在同一個 Wi-Fi（訪客網路、行動數據都不行）。
  • 「只能拖檔案進來（資料夾不行）」：把資料夾裡的檔案選起來拖，或先壓縮成 zip。
  • 連結失效了：連結 10 分鐘後失效，重新按一次傳到手機。

7翻譯

你要做什麼手機上是英文、日文、韓文看不懂，把它翻成中文蓋在原文上。翻譯在這台電腦上進行，畫面上的字不會傳到網路。

  1. 手機畫面出現後，點工具列的翻譯（或 CtrlL）。
  2. 第一次會問要不要下載翻譯模型（約 50 MB，只要一次），按下載。
  3. 看完再按一次翻譯（或 CtrlL）關掉。
{{img:translate|翻好的中文直接蓋在原文上；翻譯時畫面暫停，右上角寫「翻譯中 · 畫面已暫停」|280}}
看到這個就成功原文的位置出現中文。翻譯的時候畫面會暫停（右上角「翻譯中 · 畫面已暫停」；工具列出現時它移到工具列下面），這是正常的，關掉翻譯就恢復。
不成功怎麼辦
  • 「畫面上的文字已經是繁體中文」：畫面上本來就是中文，不用翻。
  • 日文、韓文認不出來：Windows 要加裝那個語言的「光學字元辨識」，看這裡。
  • 只想翻一小塊：右鍵選單 → 翻譯 → 翻譯框選範圍（CtrlShiftL），拖出一個框。

放大鏡：字太小

工具列的放大點一下 2 倍、再點 4 倍、再點回原樣；Ctrl＋滾輪在滑鼠位置放大。右鍵選單 → 放大鏡還有加強對比、黃字黑底等顏色（CtrlK 切換），和凍結畫面（CtrlP）。

更新

有新版本時會跳出「自在投影有新版本」，按立即更新就好：程式會先關掉，裝好後自己打開。不想現在更新就按稍後提醒。也可以在右鍵選單 → 說明 → 檢查更新。

8遠端控制：用手機操控電腦

用手機的瀏覽器看這台電腦的畫面、聽電腦的聲音、用手指操作。手機不用裝 App（iPhone 用 Safari，Android 用 Chrome）。先選你的情況：

情況用什麼誰要在電腦前
在家，手機和電腦同一個 Wi-Fi掃 QR 碼第一次要按「允許」
我自己出門在外固定網址＋密碼（要先設定 Tailscale）設定時要，之後不用
借給朋友用一下臨時帳號（建議），或臨時網址每次都要在電腦按「允許」

情境一：在家（同一個 Wi-Fi）

你要做什麼躺在沙發上，用手機操作書房的電腦。

  2. 手機連同一個 Wi-Fi，用相機掃 QR 碼，點跳出的網址。
  3. 電腦跳出「有手機想要操控這台電腦」：是你自己的手機就按允許。勾記住這支手機，下次不用再問，以後不用再按。
  4. 手機上點點一下開聲音，或右下角寫著開聲音的喇叭，就聽得到電腦的聲音（iPhone 一定要點一下）。

  • 網頁打不開：手機不在同一個 Wi-Fi，或分享器開了「AP 隔離」。看連不上。

情境二：自己在外面用（固定網址）

你要做什麼出門在外，用手機的行動網路連回家裡的電腦。網址永遠不變，用你自己設的密碼登入。電腦要裝 Tailscale（免費），手機不用裝。

一共三件事，第一次大約 15 分鐘① 電腦裝 Tailscale 並登入 → ② 讓 Tailscale 允許 Funnel（對外的網址）和 HTTPS → ③ 在自在投影設密碼、開固定網址。之後每天只要打開手機的網址。

① 電腦裝 Tailscale、註冊、登入

  1. 電腦打開 tailscale.com/download/windows，下載安裝（Windows 10 以上）。
  2. 裝好後右下角時鐘旁出現 Tailscale 圖示（找不到就點^）。在圖示上按右鍵 → Log in，會打開瀏覽器。
  3. 用 Google、Microsoft、GitHub 或 Apple 帳號登入（Tailscale 沒有自己的密碼，也不能只用 email 註冊）。第一次會問用途，選Personal use。
  4. 回到 Tailscale 圖示按右鍵，看到自己的帳號和Connected就好了。
看到這個就成功自在投影的在外面：Tailscale卡片不再寫「這台電腦還沒有 Tailscale」（如果還在，把遠端控制關掉再打開）。

② 允許 Funnel 和 HTTPS（新帳號一定要做）

新的 Tailscale 帳號預設不允許對外的網址（Funnel），也還沒開 HTTPS 憑證。只要做一次，最簡單的方法是讓自在投影帶你做：

  1. 先做下面的 ③，按開啟固定網址。
  2. 區塊寫「你的 Tailscale 帳號還沒開啟 Funnel（第一次要開一次）」（或 HTTPS 憑證）：按開啟設定頁，瀏覽器會打開 Tailscale 的網頁，用同一個帳號登入，按啟用（Enable）。
  3. 回到自在投影按我開好了，再試一次。
{{img:remote-enable|新帳號第一次開固定網址：區塊說明原因，並有「開啟設定頁」和「我開好了，再試一次」|420}}

備案（用指令，結果一樣）：

  1. 在「開始」按右鍵 → 終端機（或搜尋「命令提示字元」）。
  2. 貼上這一行，按 Enter（數字照抄就好，等一下自在投影會自己改成正確的設定）： 
    tailscale funnel --bg --https=8443 http://127.0.0.2:8091
  3. 第一次會印出一個網址，說要你同意開啟 Funnel。用滑鼠選起來複製，貼到瀏覽器打開，用同一個帳號登入，按同意（Enable）。Tailscale 會自動幫你打開 HTTPS 憑證和 Funnel。
  4. 回到終端機，如果它還在等，再執行一次同一行；看到沒有錯誤訊息就可以關掉終端機。
電腦名稱會被公開開啟 HTTPS 時，Tailscale 會說電腦名稱和你的 tailnet 名稱會記在公開的憑證紀錄裡。電腦名稱如果是你的真名，先到 Windows「設定 → 系統 → 系統資訊 → 重新命名這部電腦」改掉。

③ 在自在投影設密碼、開固定網址

  1. 遠端控制分頁最上面的允許遠端控制區塊按設定密碼（取得固定網址和臨時帳號），輸入兩次，至少 8 個字（越長越好，別的地方沒用過的）。按儲存並開啟。
  2. 第一次要等一兩分鐘：區塊寫「正在準備網址，約 1–2 分鐘」，Tailscale 正在申請 HTTPS 憑證，這段時間手機打不開。自在投影會自己測試，通了才顯示「固定網址已開啟」。
  3. 區塊變成本機網址（在外面也能連），出現大字的 https://你的電腦名稱.….ts.net:8443/ 和 QR 碼。用手機掃，或按複製網址傳給自己。
  4. 手機打開網址，只有一個密碼欄：輸入你設的密碼。登入一次，這支手機 30 天內不用再輸入。把網頁加入主畫面，以後點圖示就能連。
  5. 想讓電腦開機後就能從外面連：進階設定 → 勾開機自動開啟固定網址。
{{img:remote-preparing|第一次開：「正在準備網址，約 1–2 分鐘」（還沒有 QR 碼）|420}}
{{img:remote-fixed|固定網址開好了（示範用的假網址）|360}} {{img:phone-login|手機打開固定網址：只要輸入你設的密碼|260}}
看到這個就成功手機輸入密碼後出現電腦畫面。在外面時電腦不用有人。
不成功怎麼辦
  • 區塊寫「你的 Tailscale 帳號還沒開啟 Funnel」或「還沒開啟 HTTPS 憑證」：照上面的 ②，按開啟設定頁，啟用後按我開好了，再試一次。
  • 區塊寫「Tailscale 還沒登入」或「沒有回應」：打開電腦上的 Tailscale，登入，再按再試一次。
  • 區塊一直寫「正在準備網址」：再等一下；5 分鐘還不行會改成「網址等了 5 分鐘還連不上」，按再試一次，或先用先用臨時網址（每次會變）。
  • 已經顯示「固定網址已開啟」，手機還是打不開：看這裡。
  • 密碼錯 5 次會鎖 15 分鐘，等時間到再試。密碼忘了：只能在電腦上用進階設定 → 變更固定網址的密碼…重設。

Tailscale 步驟出處（2026-10 查閱）：tailscale.com/kb/1223（Funnel：需要 MagicDNS、HTTPS、funnel 屬性；執行 tailscale funnel 會引導你同意開啟；只能用 443、8443、10000 埠）、/kb/1311（指令 --bg、--https、off）、/docs/how-to/set-up-https-certificates（在 DNS 頁 Enable HTTPS、Let's Encrypt 憑證、名稱會公開）。

情境三：借給朋友用

你要做什麼朋友不在你家，想讓他暫時看或操作你的電腦（例如幫你看問題），用完就失效。不要把你自己的固定網址密碼給別人。兩種方法都一樣：每次朋友連進來，都要有人在電腦前按「允許」（不能「記住」）。

方法 A：臨時帳號（建議，要先開好固定網址）

  1. 電腦：遠端控制分頁最上面的本機網址（在外面也能連）區塊 → 新增臨時帳號。
  2. 帳號已經幫你取好（例如 guest-4821，可以改）。選有效時間：用一次、1 小時、24 小時或 7 天；權限：可操作或僅觀看；要讓朋友傳檔案就勾允許傳檔（手機和電腦互傳）。按建立。
  3. 按複製全部，貼給朋友。網址後面已經帶上帳號（#u=guest-4821）；密碼只顯示這一次，忘了就按重設密碼。
  4. 朋友打開網址，帳號已經填好，只要輸入密碼。你的電腦跳出「有手機想要操控這台電腦」，確認是朋友才按允許。
  5. 到期或「用一次」用完，帳號會自動刪除；也可以在下面的臨時帳號卡片按刪除，正在連的會立刻中斷。最多 10 個。
{{img:guest-new|新增臨時帳號（有效時間、權限、傳檔）|300}} {{img:guest-made|建立好了：網址（已帶上帳號）、密碼只顯示這一次|300}}
{{img:phone-login-guest|朋友打開網址：帳號已填好，只要輸入密碼|260}}

方法 B：臨時網址（不用開固定網址）

  1. 電腦：沒有固定網址時，允許遠端控制區塊按產生臨時網址；有固定網址時，進階設定 → 臨時網址（手機不用裝 App，用行動網路也能連）。約 10～20 秒後出現 QR 碼和 6 位數通行碼（小視窗的臨時網址分頁也有；小視窗的分頁依序是同一個 Wi-Fi、固定網址、Tailscale、臨時網址，和主畫面一樣）。
  2. 按複製網址把網址傳給朋友，通行碼另外告訴他。網址只能用一次，10 分鐘內有效。
  3. 朋友打開網址、輸入通行碼，你的電腦跳出「有手機想要操控這台電腦」，你要在電腦前按「允許」。
  4. 用完按停止臨時網址，或直接把遠端控制關掉。
看到這個就成功朋友的手機出現你的電腦畫面，你的電腦上方有「● 正在被遠端控制」，你隨時可以按中斷或 CtrlD。
不成功怎麼辦
  • 朋友說「這個網址已失效」：網址只能用一次、10 分鐘有效，停止後再取得一次新的。
  • 朋友一直等「請在電腦上按『允許』」：你要在電腦前按允許（臨時網址和臨時帳號都一樣，每次都要按）。
  • 「臨時網址目前從外面連不到」：按停止臨時網址再取得一次。
借完記得朋友用完後，按中斷並停止臨時網址。對方看得到你的整個螢幕：先把私人的視窗關掉。想讓他只能看，電腦上方提示列打開僅觀看。

手機上怎麼操作：直接點和觸控板

手機頁右下角有五個圖示，下面都有字：開聲音（開了以後是聲音）、放大、檔案、鍵盤、設定。在設定 → 操作方式選（下面那行小字就是兩者的差別）：

操作方式怎麼用適合
直接點（預設）手指點哪裡就按哪裡；按住半秒＝右鍵；按住拖＝拖曳大按鈕、點選單、長輩
觸控板像筆電的觸控板：手指滑動移動游標，點一下＝左鍵，兩指點＝右鍵，兩指滑＝捲動要點很小的東西、選文字
{{img:phone-bar|手機頁右下角：開聲音、放大、檔案、鍵盤、設定（示範用的假桌面）|300}}

兩指捏合放大畫面；三指點一下開關鍵盤。鍵盤面板有 Ctrl、Alt、Win、方向鍵、複製、貼上和剪貼簿。

安全須知

  • 固定網址是公開的，擋住別人的只有密碼：用夠長、別處沒用過的密碼。
  • 連著時電腦上方一直有「● 正在被遠端控制」，CtrlD 在任何程式裡都能中斷。
  • 手機 30 分鐘沒碰會自動中斷（進階設定可以改）。
  • 進階設定 → 遠端斷線後自動鎖定電腦：斷線後鎖住電腦。預設關（從外網和在家都不鎖），需要就自己打開。
  • 不再需要從外面連：進階設定裡取消勾選開機自動開啟固定網址和固定網址（在外面也能連）（取消勾選就關閉固定網址）。

做不到的事

  • 以系統管理員身分執行的視窗、UAC 確認視窗、鎖定畫面，手機都不能操作（Windows 的限制）。
  • 電腦關機、睡眠或停在登入畫面時連不上。一次只能一支手機。
其他聲音、問題排除

9聲音大小怎麼調

你要做什麼聲音太小、太大，或完全沒聲音。先看你是哪一種：

手機投影到電腦（聲音從電腦出來）

  1. iPhone：直接按 iPhone 側邊的音量鍵，電腦的音量跟著變；自在投影會記住。
  2. 電腦：右鍵選單 → 音量（例如「音量：50%」）調大，或調電腦右下角的喇叭音量。
  3. 還是沒聲音：右下角喇叭按右鍵 →「音量混合程式」，確認自在投影沒有被靜音。
看到這個就成功調音量時畫面上會短暫顯示目前的音量。

遠端控制（電腦的聲音到手機）

  1. 手機頁一開始是靜音的（iPhone 規定），點點一下開聲音，或右下角寫著開聲音的喇叭。
  2. 電腦會自動把聲音調到適當大小，手機音量預設 100% 通常就夠。還是太小：手機頁右下角設定 → 手機音量往右拉（0–400%）。100% 是電腦送來的原本大小，超過 100% 是「響度加強」：越往右越大聲，小聲的地方拉得更多，不會破音。
  3. 手機本身的音量鍵也要調大，iPhone 側邊的靜音開關要關掉。
  4. 電腦：遠端控制分頁 → 進階設定 → 聲音裡的電腦聲音傳到手機要勾著。不想讓電腦也出聲，勾同一處的手機播聲音時電腦靜音，或在手機頁設定打開電腦喇叭靜音（同一個設定，電腦會記住；臨時帳號和「僅觀看」不能改）。
{{img:phone-settings|手機頁的設定：操作方式（下面有說明）、手機音量（預設 100%，超過 100% 是響度加強，最高 400%）、電腦喇叭靜音|300}}
不成功怎麼辦
  • 頁面寫「電腦目前沒有在播放聲音」：電腦真的沒在放聲音。
  • 電腦按了 Windows 靜音：取消 Windows 靜音；想讓電腦安靜用「手機播聲音時電腦靜音」（手機頁的「電腦喇叭靜音」）。
  • 更多看遠端沒聲音、投影沒聲音。

10常見問題排除

點問題展開答案。

手機投影

手機的清單裡找不到「自在投影」
  • 確認自在投影開著（右下角有圖示）。
  • 手機和電腦連同一個 Wi-Fi，不是訪客網路，手機沒用行動數據。
  • 關掉電腦和手機的 VPN；確認防火牆有允許（見防火牆）。
  • 學校、公司、飯店的網路常常擋住，換家裡的網路或電腦開熱點。
  • 電腦上同時開著 AirServer、LonelyScreen 之類的程式，先關掉。
  • 手機 Wi-Fi 關掉再開，或重新開啟自在投影。
投影有畫面，沒有聲音
  • 按 iPhone 音量鍵調大，iPhone 側邊靜音開關關掉。
  • 電腦右下角喇叭和「音量混合程式」裡自在投影沒被靜音。
  • 換了耳機或喇叭：重新連線一次。
  • 有些影音 App 為了版權，投影時不給聲音或畫面，這不是自在投影的問題。
畫面延遲、會卡
  • 手機和電腦都連 5 GHz Wi-Fi、靠近分享器，電腦可以用網路線。
  • 右鍵選單 → 設定 → 畫面清晰度改成標準（順暢）。
  • 關掉正在大量下載的程式。
畫面糊糊的
  • 右鍵選單 → 設定 → 畫面清晰度改成「高」或「最高」；灰色不能選時，到 Microsoft Store 安裝「HEVC 影片延伸模組」。
  • 改了以後按提示旁的現在重新連線套用。
投影到一半被別人的手機換掉

右鍵選單 → 設定 → 第二支手機連上時改成維持原本的；也可以打開連線要輸入 PIN（新手機）。

防火牆：當初按了「取消」
  1. 開始 → 搜尋「允許應用程式通過 Windows 防火牆」。
  2. 按變更設定，找到「自在投影」，勾私人。
  3. 找不到就按允許其他應用程式…，選安裝資料夾的「自在投影.exe」。
開了 VPN 就連不上

投影時先中斷電腦和手機的 VPN。有些 VPN 有「允許區域網路存取」選項，打開也可以。

Android 投放（Miracast）連不上
  • 電腦的 Wi-Fi 要開著，不要同時開「行動熱點」。
  • 檢查電腦支不支援：「開始」按右鍵 → 終端機，輸入 netsh wlan show drivers，找「Wireless Display Supported」（支援無線顯示器）兩個都是 Yes 才行。
  • 是 No 或 Google Pixel：改用 Android 操控。
Android 操控斷線、下次沒自動連上
  • Android 重開機會把無線偵錯關掉（換 Wi-Fi 也常會），自在投影會提示一次「找不到之前配對過的手機……」：回開發人員選項打開無線偵錯就好，不用重新配對。
  • 手機省電模式可能在螢幕關掉後斷 Wi-Fi，連線時打開連線期間不休眠。
  • 用 CtrlD 中斷過的手機不會自己連回來：用「連接 Android（掃 QR）」再連一次，或重開自在投影。
  • 還是不行：手機「無線偵錯 → 已配對的裝置」刪掉這台電腦，重新配對。
找不到「中斷連線」

滑鼠移到畫面上方，工具列最右邊紅色按鈕；或 CtrlD；或右下角圖示按右鍵 → 中斷連線。Android 畫面上右鍵是「返回」，要選單請按 Shift＋右鍵。

翻譯沒反應，或日文、韓文翻不出來
  • 第一次要下載翻譯模型，問你時按下載（約 50 MB；日文、韓文翻成中文約 100 MB）。
  • 日文、韓文認不出來：按提示的開啟語言設定，或 Windows 設定 → 時間與語言 → 語言與地區 → 新增語言 → 選日文（韓文）→ 只勾「光學字元辨識」→ 安裝。

遠端控制

固定網址開不起來（新的 Tailscale 帳號）
  • 新帳號要先允許 Funnel 和 HTTPS：區塊上按開啟設定頁，或照② 允許 Funnel 和 HTTPS 做一次。
  • 也可以到 Tailscale 管理頁（login.tailscale.com/admin）的 DNS 頁：打開 MagicDNS，在 HTTPS Certificates 按 Enable HTTPS；再到 Access controls 加上 funnel 權限。命令列的方法比較簡單。
  • 電腦上的 Tailscale 要開著、登入。
固定網址剛開好，手機打開是 ERR_CONNECTION_CLOSED

第一次開固定網址時，Tailscale 要先申請 HTTPS 憑證，這段時間會連不上。自在投影會自己測試：區塊寫「正在準備網址，約 1–2 分鐘」時請等；通了才會顯示「固定網址已開啟」。已經顯示開啟了手機還打不開，可能是手機那邊的 DNS 還沒查到新網址（Tailscale 說最久可能要 10 分鐘），等一下再重新整理。還是不行，在電腦的進階設定取消勾選固定網址（在外面也能連），再勾回來。

手機連不上電腦
  • 在家掃 QR 打不開：手機不在同一個 Wi-Fi（訪客網路、行動數據都不行），或分享器開了 AP 隔離。
  • 固定網址打不開：電腦要開機、登入、Tailscale 開著；第一次看上一題。
  • 網頁打得開但「影像連線被擋住了」：Windows 防火牆擋住了（第一次開遠端控制時要按允許存取）、AP 隔離，或開了其他 VPN。
  • 「這個網址已失效」：重新掃一次電腦上的 QR 碼（主畫面圖示也要重加）。
遠端沒聲音、太小聲
  • 點點一下開聲音（或寫著開聲音的喇叭）；還太小，手機頁設定 → 手機音量往右拉（預設 100%，超過 100% 是響度加強，最高 400%）。
  • iPhone 靜音開關、手機音量。
  • 電腦不要按 Windows 靜音；電腦上進階設定 → 聲音 → 電腦聲音傳到手機要勾著。
固定網址的密碼忘了

只能在電腦上重設：遠端控制分頁 → 進階設定 → 變更固定網址的密碼…。手機要用新密碼重新登入。

電腦被鎖住了

遠端斷線後電腦會自動鎖定（如果有開；預設關）。用你的 Windows 密碼或 PIN 解鎖。不想要的話：進階設定 → 遠端斷線後自動鎖定電腦取消。

關掉視窗後程式還在嗎？

在，它在右下角背景待命。要完全結束：右下角圖示按右鍵 → 結束。
