# docs/tutorial

User-facing tutorial for 自在投影 / Zizai Cast, in Traditional Chinese and English.

| file | language | what |
|---|---|---|
| `自在投影教學.html` | 繁體中文 | Self-contained illustrated tutorial (inline CSS + SVG, mascot as one base64 PNG in the CSS, ~140 KB, works offline). Opened by the idle screen's 「怎麼連線？」 link and the 「使用教學」 menu item. Sections: 開始之前, iPhone / iPad, Android 投放 (Miracast), Android 無線偵錯, 功能與快捷鍵, 常見問題 (anchors `#before #iphone #miracast #adb #features #faq`, `#disconnect`, FAQ items `#faq-notfound #faq-audio #faq-lag #faq-blur #faq-takeover #faq-fw #faq-vpn #faq-miracast #faq-adb #faq-disconnect`). |
| `ZizaiCast-Guide.html` | English | The same tutorial in English, same design, CSS and mascot (byte-identical except `lang`, `<title>` and Segoe UI first in the font stacks), same ids/anchors. Opened by “How to connect?” / “User guide” when the app UI is English. |
| `使用說明.txt` | 繁體中文 | Short plain-text version (UTF-8 BOM, CRLF), meant to replace `installer/使用說明.txt`. |
| `ZizaiCast-ReadMe.txt` | English | English short plain-text version (UTF-8 BOM, CRLF); points to `ZizaiCast-Guide.html` as the full guide. |

The app opens the guide that matches its UI language (Settings → 語言 / Language).
The installer puts the guide + readme of the installation language at the top level of
the install folder, and both guides in `程式\` so either language can be opened after
the UI language is switched.

Notes for editing: the mascot is 投投 Toutou (original art,
`assets/public/toutou/toutou_340.png`, 340 px full colour, ~56 KB, generated by
`node docs/mascot/toutou/export.mjs`), embedded once as the CSS class `.m`. The QR in the
pairing diagram is a decorative pattern, not a real code. App labels quoted in the
guides must match the string table `include/pm/i18n_strings.inc` (zh column for the
Chinese files, en column for the English files), e.g. 「連接 Android（掃 QR）」 /
“Connect Android (scan QR)”. Keep both languages in sync when either one changes.
In the English files the install sub-folders keep their Chinese names (截圖, 錄影,
安裝檔, 程式) and screenshots are named `ZizaiCast_<date>_<time>.png`.
