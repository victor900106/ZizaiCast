# Glossary sources and licences

This folder (`tools/glossary/`) holds the inputs and build scripts of the translation glossary that is compiled into the app
(`translate/src/glossary_data.inc`, made with `py -3 translate/tools/make_glossary_inc.py tools/glossary`).
Published here: `SOURCES.md`, `build_glossary*.py`, `fetch_*.py`, `wd.py`, `assemble_cached.py`, `curated_*.tsv`,
`glossary_{ja,ko,en}.tsv`, `stoplist_*.txt`. Not published (download caches and intermediate / measurement files, all
regenerated by the scripts): `raw/`, `raw_l10n/`, `wikidata_*.jsonl`, `rejected*.tsv`, `stats*`, fetch logs, and the
scratch folders and tools of the development tree.

Output: `glossary_ja.tsv`, `glossary_ko.tsv` (ja / ko -> zh-Hant, Taiwan usage). Columns:
`src  zh  mode  kind  conf  source`. Rows are sorted by priority: the first row for a source term wins.

Confidence (`conf`): A = zh-tw label or hand-checked; B = zh-hant / zh-hk label (s2twp applied for Taiwan wording), or a zh-tw alias; C = zh / zh-hans converted with s2twp, or a derived form (홍대입구역 -> 홍대입구) of a B label.

Mode (`mode`): `x` = the whole block only; `s` = also inside a sentence / menu line (kept through a placeholder),
matched at word boundaries only (Japanese: not inside a run of the same script; Korean: word start, and word end or a particle).

Build: `py fetch_wikidata.py` (polite: one query at a time, User-Agent, >= 2 s between queries, Retry-After / exponential
backoff, results cached in `raw/`), then `py build_glossary.py`. Filters and stop lists: see the header of `build_glossary.py`,
`stoplist_ja.txt`, `stoplist_ko.txt`; every dropped candidate is in `rejected.tsv` with the reason.

## v1 coverage (time-boxed, 2026-10-09)
Item lists were fetched for foods / dishes / drinks / ingredients / confectionery / seasonings / fruit / vegetables,
JP + KR stations, lines, airports, admin areas, neighbourhoods and part of the JP landmarks (82,656 items in `raw/items_*.json`).
**Not fetched**: the rest of the landmark classes, and all of companies / brands / products / chains.
Labels were fetched for only the first batch (the 1,500 lowest QIDs; the label service kept truncating responses),
so the Wikidata rows in v1 are mostly well-known foods, Korean / Japanese stations and Korean places.
v2: `py fetch_wikidata.py --cached` (resumes; batches of 400), then the missing item sets without `--cached`.

## English (en -> zh-Hant, Taiwan): `glossary_en.tsv` (added 2026-10-09)
Same columns and priority order. Keys are matched **case-insensitively with whitespace collapsed** (NO SMOKING = No smoking);
the loader must do the same (done in `translate/src/preprocess.cpp` and `translate/tools/make_glossary_inc.py`). Modes: `x` whole block (the default, and forced for every
source with a negation: no / not / don't / non- / -free / without …); `s` also inside a line, whole words only (`'` and `-`
are word characters, so gluten in gluten-free is no hit) - multiword terms and unambiguous names only; **`q`** (new, curated
nutrients only: Sodium, Iron, Energy, Protein …): inside a line only when the rest of the line is an amount (Sodium 87.2 mg,
Iron 2 mg 10%), else nothing (Do not iron / Sodium benzoate untouched). A loader that does not know `q` treats it as `x` (safe).

Localisation vote: msgids of 1-4 words (letters, space, ' - & only; accelerators _ & ~ and trailing … / : removed), msgstr
normalised the same way (儲存(_S) -> 儲存), no Latin letters in it. Each project votes its own majority msgstr (a tie inside a
project abstains). Kept: >= 3 projects from >= 2 of the 4 families, top translation >= 75 % of the votes **and** every family's
own majority agrees; else `conflict` / `conflict-family` in `rejected_en.tsv` (e.g. Help: 求助 19 / 說明 12, Undo: 復原 13 /
還原 11, Details: 詳細資料 8 / 詳細資訊 5, Default: 預設 13 / 預設值 3). conf A: >= 3 families and >= 6 projects, else B. Every
vote row is whole-block (`x`). The stop list `stoplist_en.txt` removes words whose sense depends on context (Open, Closed, Exit,
Transfer, Local, Information, Security, Storage, History, Review, Table, Line, Platform, Gate, Free, Manual, Character,
Windows, Paper, Remote, Switch, License, Landscape …) and food homonyms (date, orange, turkey, chips, punch, jam, mint, toast,
cookie, must, mate, Corona, Showa, Irwin …). Wikidata rows: single words `x`, multiword `s`; dropped: taxon ranks (…屬 / 科 / 目),
category labels (beef dish, hot beverage), labels with non-Han characters, two items with one en label and different zh.
Curated rows noted `eval` (30) were added after looking at eval_web failures; `py build_glossary_en.py --no-eval` writes
`glossary_en_noeval.tsv` without them (the held-out measurement).

Build: `py fetch_l10n.py` (one request at a time, >= 0.5 s apart, cached in `raw_l10n/`), `py fetch_wikidata_en.py` (wd.py:
>= 2 s between queries, backoff, cached in `raw/en_*.json`), then `py build_glossary_en.py` -> `glossary_en.tsv`,
`rejected_en.tsv`, `stats_en.txt`. Both fetchers send only the User-Agent `ZizaiCast-glossary/1.0 (github.com/victor900106/ZizaiCast)`;
no account, e-mail or other personal data in any request. (An offline simulator of the loader on the eval_web English lines, `sim_en.py`, is a
scratch tool and not published.)
